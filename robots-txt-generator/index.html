What is Robots.txt Generator?

This tool builds two files every website should have. robots.txt tells search engines and other crawlers which parts of your site they may visit; sitemap.xml lists the pages you want them to find.

You can set rules for all crawlers or for specific ones like Googlebot and Bingbot, block AI training crawlers with one tick, add your sitemap address, and test any page path to see whether it is allowed.

What you can use it for

New websites

Create a correct robots.txt and sitemap.xml before launch.

Hiding private areas from crawlers

Keep admin, cart, account and search pages out of crawling.

Opting out of AI training

Ask crawlers such as GPTBot, Google-Extended, CCBot and ClaudeBot not to collect your content.

Checking rules

Test whether a page is blocked before you publish changes.

Small sites without plugins

Make a sitemap from a list of pages for a hand-made or static site.

Step-by-step tutorial: how to use Robots.txt Generator

  1. Start from a preset

    Choose Allow all, Block all, a typical website or WordPress. Your rules are kept in this browser for next time.

  2. Edit the rules

    For each crawler, choose Disallow or Allow and type a path that starts with /. Use * for any text and $ for the end of the address.

  3. Add crawlers

    Press Add rules for another crawler and pick one from the list or type its name.

  4. AI crawlers and sitemap

    Tick Block AI training crawlers if you want, and add your sitemap address.

  5. Test a path

    Type a path such as /admin/settings and a crawler name to see if it is allowed and which rule decides.

  6. Publish robots.txt

    Download it and upload it to the root of your site so it opens at /robots.txt.

  7. Make the sitemap

    Paste your page addresses, one per line, pick last modified, change frequency and priority, press Make sitemap, then download sitemap.xml and upload it too.

Features

  • PresetsCommon setups ready in one click.
  • Per-crawler rulesMore than 20 known crawlers in the list, or any name you type.
  • Built-in testerUses Google's rules: only the most specific matching crawler group counts (Googlebot-Image uses its own group if there is one), the longest matching path wins, Allow wins a tie, with * and $ support. A full user-agent string can be pasted as the crawler.
  • Helpful checksPaths without a leading slash are fixed and invalid sitemap addresses are flagged.
  • Sitemap generatorRemoves duplicates and fragments, encodes special characters, escapes & and warns about mixed domains.

Tips and tricks

  • Do not block CSS and JavaScript files; search engines need them to see your pages properly.
  • robots.txt is public. Do not list secret addresses in it; protect them with a password instead.
  • To keep a page out of search results, use a noindex tag and leave the page crawlable.
  • Submit your sitemap in Google Search Console and Bing Webmaster Tools too.
  • Update lastmod only when a page really changes.

Problems and how to fix them

My page is still in Google after blocking it

Blocking stops crawling, not indexing. Allow crawling and add a noindex tag, or use the removal tool in Search Console.

Crawl-delay is ignored

Google ignores Crawl-delay. Bing and Yandex use it.

Some lines were skipped in the sitemap

They were not full web addresses. Use addresses starting with https://.

My sitemap has more than 50,000 pages

Split it into several sitemaps of up to 50,000 addresses and list each one in robots.txt.

Questions and answers

Where do I put robots.txt?

At the root of your domain, so it opens at https://your-site/robots.txt. It only applies to that host.

Does robots.txt hide pages from Google?

It stops crawling, not indexing. A blocked page can still appear in results if other sites link to it. Use a noindex tag to keep a page out of search.

How are Allow and Disallow decided?

Like Google: the most specific (longest) matching rule wins, and Allow wins a tie. The tester uses the same rule, including * and $.

How many URLs can a sitemap have?

Up to 50,000 addresses and 50 MB. For bigger sites, split them into several sitemaps.

Do all AI crawlers obey robots.txt?

The major ones listed say they do, but robots.txt is a request, not a lock.
