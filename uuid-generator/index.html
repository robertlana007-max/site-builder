What is UUID Generator?

The UUID Generator creates random version 4 UUIDs, which are 128-bit identifiers written as 32 hexadecimal characters in five groups, like 3f2b8c1e-9a4d-4e7b-b6c2-1d0f5a7e9c34. You can make 1 to 500 at a time, in lower or upper case, with or without hyphens.

Developers, database administrators and testers use UUIDs as unique keys for database rows, API objects, files, sessions, orders and devices, because they can be created anywhere without checking a central list. The tool is also handy for filling test data or configuration files that need IDs.

The UUIDs are generated in your browser with its secure random source and are not stored or sent anywhere.

What you can use it for

Database primary keys

Create IDs for new rows that will not clash, even when records are made on different servers.

Test and sample data

Generate hundreds of IDs at once for seed files, spreadsheets or API tests.

File and folder names

Give uploads or exports names that will never overwrite each other.

Config files and APIs

Fill in client IDs, correlation IDs or request IDs that need UUID format.

Windows GUIDs

Tick UPPERCASE to get the style often used for GUIDs in Windows and .NET projects.

Step-by-step tutorial: how to use UUID Generator

  1. See the first batch

    When the page opens, 5 new UUIDs are already in the result box, one per line.

  2. Choose how many

    Type a number from 1 to 500 in "How many". The list refreshes immediately. Numbers above 500 are treated as 500.

  3. Pick the format

    Tick "UPPERCASE" to use capital letters A to F instead of small ones. Tick "Remove hyphens" to get 32 characters with no dashes, which some databases and URLs prefer. Each change creates a new list.

  4. Make a fresh list

    Click "Generate new" to replace the list with brand-new UUIDs using the same settings.

  5. Copy them

    Click "Copy all" to copy every UUID, one per line. Paste them into your code, a spreadsheet column or a text file.

Features

  • Version 4 (random) UUIDsStandard RFC 4122 format with 122 random bits, made with the browser’s crypto random generator.
  • Bulk generationCreate from 1 up to 500 UUIDs in one go.
  • Upper or lower caseMatch the style your system or team expects.
  • Optional hyphensKeep the standard 8-4-4-4-12 layout or get a compact 32-character string.
  • One per lineThe list pastes neatly into spreadsheets and code.
  • Copy allCopy the whole list with one click.

Worked example: IDs for a test spreadsheet

You need IDs for 100 test customers. Type 100 in "How many". The box fills with 100 lines such as "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d", each 36 characters long. Click "Copy all", click cell A2 in your spreadsheet and paste; each UUID goes into its own row. Note the 4 at the start of the third group: it marks the UUID as version 4.

Tips and tricks

  • Store UUIDs in a native UUID column type where your database has one; it takes less space than text.
  • Random UUIDs are not in time order. If you need IDs that sort by creation time, your database may offer a different type.
  • Do not use a UUID as a password or secret token. It is unique, but it is not meant to be secret.
  • Hyphens and case do not change the value. 9B1DEB4D3B7D4BAD9BDD2B0D7B3DCB6D is the same UUID as the lower-case version with hyphens.

Problems and how to fix them

The list changed before I copied it

Changing "How many", "UPPERCASE" or "Remove hyphens" creates a new list. Set the options first, then copy.

My system rejects the UUID

Check whether it expects hyphens and lower case. The standard form is lower case with hyphens, so untick both boxes.

I typed 1000 but got only 500

The tool makes at most 500 at a time. Copy them, then click "Generate new" for another batch.

"Copy all" did not work

Your browser may block the clipboard. Click in the box, press Ctrl+A to select all and Ctrl+C to copy.

Questions and answers

What is a UUID?

A 128-bit identifier written as 32 hexadecimal digits. It is designed to be unique without a central authority handing out numbers.

Can two UUIDs be the same?

In theory yes, but version 4 has 122 random bits, so a collision is so unlikely it can be ignored in practice.

Is a GUID the same as a UUID?

Yes. GUID is the name Microsoft uses for the same thing.
