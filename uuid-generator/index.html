Questions people ask

What is a UUID?

A 128-bit identifier written as 32 hexadecimal digits. It is designed to be unique without a central authority handing out numbers.

Can two UUIDs be the same?

In theory yes, but version 4 has 122 random bits, so a collision is so unlikely it can be ignored in practice.

Is a GUID the same as a UUID?

Yes. GUID is the name Microsoft uses for the same thing.
