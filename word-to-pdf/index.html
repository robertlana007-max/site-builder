What is Word to PDF?

Word to PDF turns a Word document (.docx) into a PDF that looks the same on every phone, computer and printer. It is the usual way to send a CV, letter, invoice or assignment so nobody can change it by accident.

The tool first shows a preview of your document, then builds a PDF with real, selectable and searchable text. Pictures, tables, colours, bullet lists, headers and footers are kept. For the closest match to your own fonts you can also print to PDF with your browser.

Your document is read inside your browser and never uploaded.

What you can use it for

Send a CV or cover letter

Employers often ask for PDF so the layout stays exactly as you made it.

Hand in school or university work

Upload portals usually want a PDF that cannot be edited.

Share invoices and quotes

A PDF looks professional and opens on any device.

Print reliably

PDFs print the same everywhere, without missing fonts or moved pictures.

Convert on a computer without Word

Make a PDF on a library or work computer that has no Office installed.

Step-by-step tutorial: how to use Word to PDF

  1. Choose your .docx file

    Click the box that says "Click or drop a Word file (.docx) here", or drag the file onto it.

  2. Check the preview

    Your pages appear in a grey box below the buttons, so you can see the document was read correctly.

  3. Press "Make PDF"

    The tool lays out the pages and shows a progress bar. Long documents take a few seconds.

  4. Download the PDF

    Click "Download PDF". The file has the same name as your document with .pdf at the end.

  5. Or use "Print → Save as PDF"

    This opens your browser's print window. Choose "Save as PDF" (or "Microsoft Print to PDF" on Windows) as the printer and click Save. This keeps your exact fonts.

Features

  • Selectable textThe PDF holds real text, so it can be searched, copied and read by screen readers.
  • Live previewSee your document before you make the PDF.
  • Pictures, tables and coloursImages, table borders, shading, highlights and coloured text are kept.
  • Lists, headers and footersBullets and numbering are kept, and headers and footers are repeated on every page.
  • All languagesArabic, Urdu, Hebrew, Hindi, Bengali, Tamil and Thai are real text; Chinese, Japanese, Korean and emoji are kept as sharp pictures.
  • Two ways to saveMake PDF for a quick file, or Print → Save as PDF for the most exact look.
  • PrivateNothing is uploaded.

Worked example: sending a CV as PDF

Tom has cv.docx with a photo, two headings and a table of skills. He drops it on the tool and sees the preview of his 2 pages. He presses "Make PDF", the message says "PDF ready: 2 pages", and he downloads cv.pdf to attach to his job application.

Tips and tricks

  • Old .doc files are not supported. Open them in Word, LibreOffice or Google Docs and choose Save as .docx first.
  • If letters look slightly different from your document, use Print → Save as PDF, which uses your installed fonts.
  • In the print window, turn off "Headers and footers" so the browser does not add the date and web address.
  • Password-protected documents must be unlocked in Word first.
  • Check page breaks in the PDF; text can move slightly when fonts differ from the ones used in Word.

Problems and how to fix them

It says the file is an old .doc file

This tool reads .docx only. Save the file as .docx in Word, LibreOffice or Google Docs and try again.

The fonts look different

Make PDF draws text with the Noto Sans font. Use Print → Save as PDF to keep your own fonts.

A drawing or chart is missing

Some Word drawings, charts and equations cannot be shown in the browser. Save them as pictures in Word first.

Some characters cannot be selected

Chinese, Japanese and Korean letters and emoji are added as sharp pictures. Use Print → Save as PDF if you need to select those words.

Questions and answers

Is my document uploaded?

No. The document is read and the PDF is made inside your browser.

Can I convert old .doc files?

No. Open the .doc in Word, LibreOffice or Google Docs, save it as .docx, then convert.

Why do the letters look a little different?

Make PDF draws the text with the Noto Sans font. Use Print → Save as PDF to keep the fonts installed on your device.

Can I select and copy text in the PDF?

Yes. The PDF holds real text, so it can be searched and copied.

Are pictures and tables kept?

Yes. Pictures, table borders, shading, colours, lists, headers and footers are kept. Some Word charts and equations may not appear.
