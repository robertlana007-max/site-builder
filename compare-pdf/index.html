What is Compare PDF?

Compare PDF shows the differences between two versions of the same document. It reads the text of both whole files and marks every word that was removed or added, so text that only moved to the next page is not counted as a change.

Text is only half the story, so the tool can also draw both versions of a page on top of each other. Ink that is only in the first file shows in red, ink only in the second shows in blue, and side by side view puts red boxes around every area that changed.

Both files are opened with pdf.js inside your browser and are never uploaded.

What you can use it for

Contract changes

See what the other side changed in a revised contract before you sign it.

Proofreading

Check that only the corrections you asked for were made in a new print proof.

Document versions

Find what changed between two versions of a policy, manual or report.

Designs and drawings

Spot moved logos, changed figures or shifted lines with the overlay view.

Exam papers and forms

Make sure two copies of a form or test are really identical.

Step-by-step tutorial: how to use Compare PDF

  1. Choose the first PDF

    Click the left box ("First (old)") and pick the older version. Its page count and size appear in the box.

  2. Choose the second PDF

    Click the right box ("Second (new)") and pick the newer version. You can also drop both files at once on one box.

  3. Compare

    Press Compare PDFs. The summary shows the page counts, how many pages changed, and how many words were removed and added.

  4. Pick a page

    Page buttons in red have changes. A dashed button is a page that exists in only one file. The first changed page opens automatically.

  5. Read the text changes

    Removed words are red and crossed out, added words are green. Unchanged text is shown around them for context.

  6. Check the pictures

    Press Overlay to see both pages on top of each other, or Side by side to see them next to each other with red boxes around changes.

  7. Fine-tune

    Tick Ignore capital letters or Ignore punctuation, or press Swap first and second to reverse the comparison.

Features

  • Word-level differencesEach added and removed word is marked, not just whole lines.
  • Visual overlayRed and blue show ink that exists in only one version.
  • Side by side with boxesChanged areas are outlined on both pages.
  • Page summarySee at a glance which pages changed and which exist in only one file.
  • Works with scansPicture comparison works even when there is no text.
  • PrivateNothing leaves your device.

Worked example: a revised lease

Priya receives lease-v2.pdf after asking for one change. She chooses lease-v1.pdf as the first file and lease-v2.pdf as the second, and presses Compare PDFs. The summary says 2 pages have changes. Page 3 shows "30 days" crossed out and "60 days" in green, as she asked, but page 5 also shows "deposit of 1 month" changed to "2 months", which nobody mentioned. She asks about it before signing.

Tips and tricks

  • Always put the older version first, so red means removed and green means added.
  • If the whole page shows as changed in the overlay, the layout probably moved a little; read the text changes instead.
  • Use Ignore capital letters when one version was retyped with different capitals.
  • For long documents, jump straight to the red page numbers.

Problems and how to fix them

Every word on a page is marked as changed

The text may be stored very differently in the two files, for example one is a scan. Use Overlay to compare the look instead.

"These PDFs have no text"

Both files are scans or images. Overlay and Side by side still show the differences.

A file is password protected

Remove the password with the Unlock PDF tool first, then compare.

Questions and answers

What counts as a change?

Every word that is in one PDF but not in the other, page by page. The Overlay and Side by side views also show changes in pictures, lines and layout that text cannot show.

Can it compare scanned PDFs?

Scans have no text, so the word list stays empty, but Overlay and Side by side still compare them as pictures.

What if one PDF has more pages?

Extra pages are shown with a dashed border and listed as only in the first or only in the second PDF. Because the whole text is compared, words that simply moved onto another page are not shown as changes.

Can I ignore small differences?

Yes. Tick Ignore capital letters or Ignore punctuation to hide changes that only affect those.

Are my files uploaded?

No. Both PDFs are read and compared inside your browser.
