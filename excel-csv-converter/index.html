What is Excel to CSV Converter?

Excel to CSV Converter changes spreadsheets between formats: Excel (.xlsx, .xls), OpenDocument (.ods), CSV, TSV and JSON. You can turn a workbook into a CSV for another program, or a CSV back into a proper Excel file.

You pick the sheet, see a preview table of the rows, and choose the separator and text options, including the UTF-8 marker that makes Excel show accents and other alphabets correctly.

Everything runs in your browser using the SheetJS spreadsheet library, so your data is never uploaded.

What you can use it for

Import data into another program

Many websites, banks, shops and databases accept only CSV files.

Open a CSV in Excel properly

Convert a CSV to .xlsx so leading zeros, accents and columns come out right.

Prepare data for developers

Turn a sheet into JSON for an app, a website or an API test.

Convert old .xls files

Save old Excel 97–2003 files as modern .xlsx.

Fix separators for your region

Make a semicolon-separated CSV for Excel in Europe, or a comma one for the US and UK.

Step-by-step tutorial: how to use Excel to CSV Converter

  1. Choose your file

    Click the box or drop a spreadsheet, CSV, TSV or JSON file onto it. A preview of the first rows appears.

  2. Pick the sheet

    If the workbook has more than one sheet, choose the one you want in the Sheet menu.

  3. Choose the format

    In "Convert to" pick CSV, TSV, JSON, Excel workbook (.xlsx) or OpenDocument (.ods).

  4. Set the options

    For CSV choose the separator. Keep "Add a UTF-8 marker" ticked if the file will be opened in Excel. For JSON, say whether the first row holds the column names.

  5. Press Convert

    The result appears with its size. For text formats the first part is shown in a box and can be copied.

  6. Download

    Click the green Download button to save the file.

Features

  • Many formatsRead .xlsx, .xlsm, .xls, .ods, CSV, TSV and JSON; write CSV, TSV, JSON, .xlsx and .ods.
  • Sheet picker and previewChoose any sheet and check the rows before converting.
  • Separator choiceComma, semicolon, tab or pipe.
  • Excel-friendly UTF-8An optional byte order mark makes Excel show é, ü, Cyrillic and Chinese correctly.
  • Smart CSV readingDetects the separator, handles quotes and line breaks inside cells, and keeps leading zeros like 007.
  • EncodingsReads old CSV files saved as Windows-1252, Latin-1, UTF-16, Shift_JIS and more.
  • PrivateFiles are converted on your device.

Worked example: product list for an online shop

Lena has products.xlsx with two sheets, Products and Notes. She drops it on the tool, keeps the Products sheet, chooses CSV with a comma separator and leaves the UTF-8 marker ticked. She presses Convert, sees "Done: 248 rows" and downloads products-Products.csv, which her shop website imports without broken accents.

Tips and tricks

  • Formulas are saved as their last calculated values, not as formulas.
  • CSV and JSON hold only one sheet. Convert each sheet separately if you need them all.
  • If a CSV shows all data in one column in Excel, try the semicolon separator.
  • Untick "Turn number text into real numbers" to keep every value exactly as typed.
  • Colours, fonts, charts and pictures cannot be stored in CSV, TSV or JSON.

Problems and how to fix them

Accents look wrong in Excel

Tick "Add a UTF-8 marker (BOM)" and convert again. When reading an old CSV, choose Windows-1252 in the reading options.

Everything is in one column

The separator does not match. Change "Columns are separated by" when reading, or the CSV separator when writing.

Dates show as numbers

Tick off "Write numbers as stored" so dates are written the way the sheet shows them.

It says the file is password protected

Remove the password in Excel, save, and try again.

Questions and answers

Is my spreadsheet uploaded?

No. The file is read and converted in your browser.

Why do accents look wrong when I open the CSV in Excel?

Keep "Add a UTF-8 marker (BOM)" ticked. Excel then reads the file as UTF-8 and shows all letters correctly.

Can I convert all sheets at once?

Excel and ODS output keep every sheet. CSV, TSV and JSON hold one sheet, so convert the others one by one.

Are formulas kept?

Formulas are saved as their last calculated values.

Are leading zeros kept?

Yes. Values like 007 or 0042 stay as text when a CSV is read.

Which library does it use?

SheetJS Community Edition, an open-source spreadsheet library that runs in your browser.
