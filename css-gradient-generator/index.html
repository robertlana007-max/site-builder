What is CSS Gradient Generator?
The CSS Gradient Generator builds linear, radial and conic gradients visually and gives you CSS you can paste straight into a stylesheet. You see the result on a large preview while you pick colors, move color stops and change the angle.
It is for web designers, developers and anyone making a website, email banner or app screen who wants a smooth color blend without an image file. Gradients load instantly and stay sharp on every screen size.
Everything runs in your browser; nothing is uploaded.


What you can use it for
Website backgrounds
Create a hero section or page background that blends two or more brand colors.
Buttons and cards
Give buttons, badges and cards a subtle color fade that looks modern.
Color wheels and pie effects
Use a conic gradient for a color wheel, a progress ring or a simple pie chart look.
Spotlight effects
Use a radial gradient with the center moved to a corner for a soft glow.
Striped patterns
Turn on Repeating to make stripes and rings from just a few color stops.


Step-by-step tutorial: how to use CSS Gradient Generator
  1. Choose the type
    Pick Linear for a straight blend, Radial for a blend that spreads out from a point, or Conic for colors that sweep around a center like a clock hand.
  2. Set the direction
    For linear and conic gradients, drag the Angle slider. 90° goes left to right, 180° goes top to bottom. For radial and conic gradients, move Center X and Center Y to place the center.
  3. Edit the colors
    Each color stop has a row with a color picker, an Opacity slider and a Position in percent. Click a row's color square to change it.
  4. Add and move stops
    Click anywhere on the stop bar to add a color at that point; the new color is blended from its neighbors. Drag the small markers under the bar to move stops, or type an exact position. On a keyboard, focus a marker and use the arrow keys.
  5. Try presets and random
    Click a preset swatch to start from a ready-made gradient, or press Random for a fresh color idea. Reverse flips the order of the colors.
  6. Copy the CSS
    Click Copy CSS for both lines (a solid fallback color and the gradient) or Copy gradient only to get just the gradient value, for example to use inside another property.


Features
  • Three gradient typesLinear, radial (circle or ellipse) and conic gradients, each with a repeating version.
  • Draggable color stopsAdd up to 16 stops and drag them along a bar, or type exact positions.
  • TransparencyEach stop has its own opacity; transparent colors are written as rgba().
  • Live previewThe big preview updates as you drag sliders and markers.
  • Fallback colorThe CSS includes a plain background color for very old browsers and email clients.
  • Presets and random ideasTen ready gradients and a random generator based on pleasing color spacing.


Worked example: a sunset button
Choose Linear, set the angle to 135°, then pick #f6d365 for the first stop and #fda085 for the second. The CSS reads background: #f6d365; background-image: linear-gradient(135deg, #f6d365 0%, #fda085 100%);. Paste both lines into your button rule. Add a third stop at 50% with opacity 60% to make the middle softer; that stop is written as rgba(…, 0.6) 50%.


Tips and tricks
  • Two or three colors that sit near each other on the color wheel usually look smoother than opposite colors.
  • If the middle of a two-color gradient looks muddy, add a stop in the middle with a brighter color.
  • Put two stops at the same position to make a hard edge instead of a blend, which is how stripes are made.
  • Text on a gradient needs enough contrast at both ends; check the lightest part of the gradient.
  • Gradients are drawn by the browser, so they are tiny compared with image backgrounds and never look blurry.


Problems and how to fix them
The gradient does not show
Make sure you copied both lines, or that nothing later in your CSS sets background again and overrides it.
The angle seems wrong
In CSS, 0° points up and angles turn clockwise, so 90° goes left to right. Some design apps measure angles differently.
I cannot remove a color
A gradient needs at least two colors, so the remove button is disabled when only two remain.
Conic gradients look different in an old browser
Conic gradients need a browser from 2020 or later. The fallback color is shown in older ones.



Questions and answers


Which browsers support these gradients?
Linear and radial gradients work in every current browser. Conic gradients need a browser from 2020 or later; the CSS includes a solid fallback color.
How do I make a transparent gradient?
Lower the Opacity slider on a color stop. That stop is written as an rgba() color, so whatever is behind the element shows through.
How many colors can I use?
Up to 16 color stops. Click the stop bar or press Add color to add one.
Can I make stripes?
Yes. Turn on Repeating, or put two stops at the same position to create a sharp edge.
Is the code free to use?
Yes. The CSS you create is yours to use in any project.
