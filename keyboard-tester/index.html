What is Keyboard Tester?

Keyboard Tester lights up each key on a full-size on-screen keyboard as you press it, so you can quickly check that every key on your keyboard works.

For each press it shows the key name, the code, the old keyCode number and where the key is (left, right or numpad). A list shows every key held down right now, which helps you find stuck keys and test how many keys can be pressed together (ghosting and rollover).

It works with any physical keyboard and nothing you type is sent anywhere.

What you can use it for

Check a new or second-hand keyboard

Press every key and see which ones turn green.

Find a broken or sticky key

A key that never lights up, or stays lit, is easy to spot.

Test gaming keyboards

Hold several keys at once to see how many your keyboard can report together.

Check after a spill or cleaning

Make sure every key still works after drying or removing keycaps.

Find key codes for programming

Read the exact key, code and keyCode values for your scripts and shortcuts.

Step-by-step tutorial: how to use Keyboard Tester

  1. Choose your layout

    Pick ANSI (US style) or ISO (UK and Europe, with a tall Enter key).

  2. Press keys

    Each key turns blue while held down and green once it has worked.

  3. Read the details

    The boxes show the last key's name, code, keyCode and location, and how many keys you have tested.

  4. Hold several keys

    Hold keys together; they appear in "Keys held down now" and "Most held at once" shows the highest number.

  5. Look at the history

    The table lists every press, repeat and release with the time.

  6. Reset

    Press "Reset test" to start again.

Worked example: a key that does not work

Leo's laptop sometimes misses the letter E. He presses every letter on the keyboard tester; all turn green except E, which only lights up when pressed hard. The history shows several missing presses, so he cleans under the keycap and tests again until E works every time.

Tips and tricks

  • Click on the page first so it has the keyboard focus.
  • Some keys never reach websites: Fn, Ctrl+Alt+Delete, Windows-key shortcuts, Ctrl+W, Ctrl+T and media keys.
  • Print Screen often reports only its release; it still counts as working.
  • Many cheap keyboards can only report 2 or 3 letter keys at once; gaming keyboards often report 6 or more.
  • Switch the layout to ISO if your keyboard has a tall Enter key and an extra key next to left Shift.

Problems and how to fix them

Nothing lights up

Click on the page so it has focus, and make sure you are not typing in another box.

A key lights up as a different key

Your system keyboard layout may differ (for example AZERTY). The code shows the physical key position.

Keys stay blue after I let go

The browser missed the release, often after switching windows. Press the key again or press Reset.

Some combinations do not show all keys

That is ghosting: your keyboard cannot report those keys together. It is a hardware limit.

Questions and answers

Is what I type saved or sent anywhere?

No. Key presses are shown on this page only and are forgotten when you leave.

Why do some keys not light up?

Some keys never reach websites, such as Fn, Ctrl+Alt+Delete, Windows-key shortcuts and media keys. Other keys that stay grey may be faulty.

What is ghosting?

Some keyboards cannot report certain keys pressed together. Hold the keys; any that do not light up are not detected.

What is the difference between key and code?

key is the character the key types in your layout; code is the physical key position, which stays the same in every language.

Does it work on a phone?

Use the "Type here" box to test a keyboard connected to a phone or tablet. On-screen keyboards often report keys as Unidentified.
