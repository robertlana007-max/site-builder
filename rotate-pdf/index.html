How to use Rotate PDF

  1. Choose a PDF.
  2. Choose the direction to rotate.
  3. Leave Pages empty for the whole file, or type the pages to rotate.
  4. Click Rotate PDF, then Download.

Questions and answers

Is the rotation permanent?

Yes. The downloaded file opens rotated in every PDF reader.

Can I rotate only some pages?

Yes. Type the pages, for example 2, 5-7.

Does rotating change quality?

No. Only the page direction changes.
