What is Markdown to HTML?
Markdown to HTML turns plain Markdown text into clean HTML, with a live preview beside your writing. You can copy the HTML, see the source code, or download a complete .html web page or your .md file.
It is handy for writers, bloggers, students and developers: preparing a README, a blog post, documentation, or notes that need to go into a website or email template.
It supports GitHub-flavoured Markdown, including tables, task lists, strikethrough and fenced code blocks. The output is always cleaned, so scripts and other unsafe code are removed. Everything happens in your browser.


What you can use it for
Blog posts and CMS
Write in Markdown and paste the HTML into a website editor that only accepts HTML.
README and docs
Check how a README with tables and code blocks will look before you push it.
Email newsletters
Draft in Markdown and copy the HTML into your email template.
Sharing a formatted page
Download a complete .html file that anyone can open in a browser.
Learning Markdown
Load the sample to see each feature and how it turns into HTML.


Step-by-step tutorial: how to use Markdown to HTML
  1. Add your Markdown
    Type or paste Markdown into the Markdown box, click Open .md file to load one from your device, or press Load sample to start from an example.
  2. Watch the preview
    The Preview tab updates as you type, showing headings, lists, tables, task lists, code and quotes as they will look.
  3. See the HTML
    Click HTML source to see the generated code. This is exactly what Copy HTML copies.
  4. Choose line break style
    By default a single line break joins lines into one paragraph, as in standard Markdown. Tick "Treat single line breaks as <br>" to keep each line separate, like GitHub comments.
  5. Copy the HTML
    Click Copy HTML to put the HTML on your clipboard, ready to paste into a website, CMS or template.
  6. Download files
    Download .html saves a full web page with a title taken from your first heading and simple styling. Download .md saves your Markdown text.

Worked example: a small table
You type three lines: | Tool | Free |, then | --- | --- |, then | Regex Tester | Yes |. The preview shows a table with a header row Tool and Free and one row Regex Tester, Yes. The HTML source shows <table>, <thead> with two <th> cells, and <tbody> with two <td> cells. Click Copy HTML and paste it into your website's HTML editor.


Tips and tricks
  • Leave a blank line between paragraphs, lists, tables and code blocks so they are recognised.
  • Put the language after the opening ``` of a code block, like ```js, so the code gets a language class for syntax highlighters.
  • Write task list items as - [ ] to do and - [x] done.
  • Use a colon in the table divider row to align columns: :--- left, :---: centre, ---: right.
  • Start the document with a # heading: it becomes the title and file name of the downloaded page.


Problems and how to fix them
My HTML or script disappeared
Unsafe code such as <script>, onclick attributes, iframes, forms and <style> blocks is always removed for safety. Normal tags like <div>, <span>, <details> and <img> are kept.
My lines run together
Markdown joins lines within a paragraph. Leave a blank line between paragraphs, end a line with two spaces, or tick "Treat single line breaks as <br>".
The table does not appear
A table needs a header row, a divider row like | --- | --- | and a blank line before it.
The .md file will not open
Only plain text files can be opened, such as .md, .markdown or .txt. Word or PDF files need to be converted to text first.



Questions and answers


Which Markdown features are supported?
Headings, bold, italic, links, images, lists, quotes, code, and the GitHub extras: tables, task lists, strikethrough, fenced code blocks and automatic links.
Can I use HTML inside my Markdown?
Yes. Normal HTML is kept, but scripts, event handlers like onclick, javascript: links, iframes, forms and style blocks are removed for safety.
What is in the downloaded .html file?
A complete web page with a title from your first heading and simple, readable styling. It opens in any browser.
Is my text uploaded?
No. The conversion runs in your browser and your text is not saved or sent anywhere.
