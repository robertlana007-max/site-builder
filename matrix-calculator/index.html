What is Matrix Calculator?

The Matrix Calculator adds, subtracts and multiplies matrices up to 6×6, multiplies by a number, and finds the transpose, determinant, inverse, rank and reduced row echelon form (RREF). Every elimination step can be shown.

It keeps answers as exact fractions when you enter whole numbers or fractions, which is what most linear algebra courses expect, and switches to decimals when you enter decimals.

It is free, works on phones, and does all the calculations in your browser.

What you can use it for

Linear algebra homework

Check determinants, inverses and RREF with every row operation listed.

Solving linear systems

Row reduce an augmented matrix to read off the solution.

Checking invertibility

See whether a matrix is singular from its determinant and rank.

Matrix products

Multiply matrices for transformations, Markov chains or graphics, with clear size errors if they do not fit.

Teaching

Generate exact worked examples of Gauss–Jordan elimination for a lesson.

Step-by-step tutorial: how to use Matrix Calculator

  1. Set the sizes

    Choose the number of rows and columns for A and for B, from 1 to 6.

  2. Fill in the entries

    Type whole numbers, fractions like 2/3, decimals or expressions like sqrt(2). Empty cells count as 0. Press Enter or the arrow keys to move between cells.

  3. Use the helpers

    Clear, Identity and Random fill a matrix quickly, and Swap A ↔ B exchanges them.

  4. Pick an operation

    Use A + B, A − B, A × B, B × A or k × A for two matrices. For one matrix choose A or B, then Determinant, Inverse, RREF, Rank, Transpose or Square.

  5. Read the result and steps

    The result appears in the blue box. Press "Show the steps" to see each row operation, such as R2 → R2 − 3·R1, with the matrix after it.

  6. Reuse the result

    Press Use as A or Use as B to continue with the answer, or Copy result to paste it as tab-separated rows into a spreadsheet.

Features

  • Up to 6×6All operations work for any size up to six rows and six columns.
  • Exact fractionsInteger and fraction input gives exact answers like 1/60, with no rounding errors.
  • Row operations shownDeterminant, inverse, rank and RREF list every swap, scaling and elimination.
  • Clear size errorsFor example: A × B needs the columns of A to equal the rows of B, with both sizes stated.
  • Accurate decimalsWith decimal input, partial pivoting keeps results stable.
  • Copy to spreadsheetsResults copy as tab-separated rows.

Worked example: the inverse of a 2×2 matrix

Enter A = [[1/2, 1/3], [1/4, 1/5]] and press Determinant: det = (1/2)(1/5) − (1/3)(1/4) = 1/10 − 1/12 = 1/60. Because it is not 0, A has an inverse. Press Inverse: the tool row reduces [A | I] to [I | A⁻¹] and gives A⁻¹ = [[12, −20], [−15, 30]]. You can check: (1/2)(12) + (1/3)(−15) = 6 − 5 = 1, the top-left entry of the identity.

Tips and tricks

  • A matrix has an inverse only if it is square and its determinant is not 0.
  • A × B is usually different from B × A; try both.
  • The rank equals the number of pivots (leading 1s) in the RREF.
  • Swapping two rows changes the sign of the determinant; adding a multiple of one row to another does not.
  • To solve a system, put the coefficients and the right-hand side in one matrix and use RREF.

Problems and how to fix them

It says the sizes do not match

For + and − both matrices must be the same size. For A × B the number of columns of A must equal the number of rows of B.

A cell is outlined in red

That entry could not be read. Use numbers, fractions like 3/4, or expressions like sqrt(2); letters are not allowed.

The answer is in decimals, not fractions

At least one entry was typed as a decimal or uses sqrt or pi. Type fractions like 1/2 instead of 0.5 for exact answers.

It says the matrix has no inverse

The matrix is singular: its rows depend on each other, its determinant is 0 and its rank is less than its size.

Questions and answers

Are answers exact?

Yes, when you enter whole numbers or fractions the answers are exact fractions. Decimal input gives decimal answers.

Why does A × B give an error?

Matrix multiplication needs the number of columns of A to equal the number of rows of B. The message states both sizes.

When does a matrix have no inverse?

When it is not square, or when its determinant is 0 (it is singular). The tool tells you and shows the rank.

What is RREF?

Reduced row echelon form: each pivot is 1 and is the only non-zero entry in its column. It is used to solve systems and find the rank.

Can I use the result again?

Yes. Press Use as A or Use as B, or Copy result to paste into a spreadsheet.
