Frequently asked questions

What is a hash?

A fixed-length fingerprint of some data. The same input always gives the same hash, and a tiny change gives a completely different one.

Can a hash be reversed?

No. Hashes are one-way. The original text cannot be calculated from the hash.

Which one should I use?

SHA-256 is the usual choice. SHA-1 is no longer considered secure and is included only for checking old values.
