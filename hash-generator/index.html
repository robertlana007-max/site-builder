What is Hash Generator?

The Hash Generator calculates five hashes of any text or file at the same time: MD5, SHA-1, SHA-256, SHA-384 and SHA-512. A hash is a fixed-length string of letters and numbers that works like a fingerprint for the data. The same text or file always gives the same hash.

It helps developers, testers and students who need to compare values, check test data, build a signature or learn how hashing works. Use it when a system shows you a hash and you want to check which text produced it, or when you need a SHA-256 value for a test.

The SHA hashes are calculated by your browser’s built-in crypto engine and MD5 by a small script on the page, so your text and files are never uploaded.

What you can use it for

Check a known value

Type a text and compare its SHA-256 with a hash from documentation or a database to see if they match.

Create test data

Make SHA hashes for unit tests, sample data or API examples.

Learn how hashes behave

Change one letter and watch every hash change completely. This shows why hashes are good fingerprints.

Compare two texts quickly

Hash two long texts one after another. If the hashes are the same, the texts are exactly the same.

Check a download or an old value

Drop a downloaded file on the box and compare its MD5 or SHA-256 with the checksum on the download page. MD5 and SHA-1 are also shown for older systems that still use them.

Step-by-step tutorial: how to use Hash Generator

  1. Type or paste your text

    Click in the “Text to hash” box and type or paste your text. Every character counts, including spaces and line breaks. Until you type something, the rows show –.

  2. Or hash a file

    Click the box under the text, or drop a file on it. The file is read on your device and the message under the box shows its name and size.

  3. Watch the hashes update

    The five rows “MD5”, “SHA-1”, “SHA-256”, “SHA-384” and “SHA-512” update as you type. There is no button to press.

  4. Choose the hash you need

    SHA-256 is the most common. SHA-384 and SHA-512 are longer. MD5 and SHA-1 are only for checksums and old values.

  5. Click “Copy” on the right row

    Each row has its own “Copy” button. Click it to copy that hash as lowercase hexadecimal. Typing in the box again switches back from the file to the text.

Features

  • Five hashes at onceMD5 (32 characters), SHA-1 (40), SHA-256 (64), SHA-384 (96) and SHA-512 (128) are shown together.
  • Live updateHashes are recalculated on every keystroke, with no button to press.
  • UTF-8 inputText is turned into UTF-8 bytes first, which matches most programming languages and command-line tools.
  • Lowercase hex outputResults are lowercase hexadecimal, the standard format used by tools like sha256sum.
  • Separate Copy buttonsCopy exactly the hash you need without selecting text by hand.
  • Built-in browser cryptoThe SHA hashes use the browser’s Web Crypto engine, the same tested code websites use for security.
  • Files tooChoose or drop any file to get its checksums, for example to check a download. Nothing is uploaded.

Worked example: hashing the word hello

Type hello in lowercase with no space after it. The “SHA-256” row shows 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824. The “SHA-1” row shows aaf4c61ddcc5e8a2dabede0f3b482cd9aea9434d. Now type an exclamation mark so the text is hello! and the SHA-256 becomes ce06092fb948d9ffac7d1a376e404b26b7575bcc11ee05a4615fef4fec3a308b, which looks nothing like the first one. Change it to Hello with a capital H and the SHA-256 is 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969, so capital letters matter too.

Tips and tricks

  • Hashes are case-sensitive and space-sensitive. Hello, hello and hello with a space give three different results.
  • When the box is empty, the rows show – instead of a hash. Empty text does have a hash, but showing it before you type only causes confusion.
  • Command-line tools like echo add a line break at the end. If your hash does not match, press Enter after your text in the box and compare again.
  • For anything new, use SHA-256 or longer. MD5 and SHA-1 are broken for security use and are only for checksums.
  • Do not use a plain SHA hash to store passwords. Real systems use slow password hashes such as bcrypt or Argon2.

Problems and how to fix them

“Your browser does not support SHA hashing on this page.”

The browser crypto engine only works on secure pages. Open the site with https:// in the address, or try an up-to-date browser. MD5 still works.

My hash does not match the expected value

Check for a trailing space or line break, different capital letters, or a different algorithm. Also check if the other value was made from a file and not text.

My MD5 does not match

Check for a trailing line break or space first. If you are checking a file, drop the file itself instead of pasting its contents as text.

I want the hash of a file

Click the box under the text or drop the file on it. Very large files (several hundred MB) are read into memory and can take a while on a phone.

Questions and answers

What is a hash?

A fixed-length fingerprint of some data. The same input always gives the same hash, and a tiny change gives a completely different one.

Can a hash be reversed?

No. Hashes are one-way. The original text cannot be calculated from the hash.

Which one should I use?

SHA-256 is the usual choice. MD5 and SHA-1 are no longer considered secure and are included only for checksums and old values.
