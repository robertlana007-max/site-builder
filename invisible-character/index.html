What is Invisible Character?

This tool does two things. First, it lets you copy invisible and blank characters, such as Hangul Filler, Braille Pattern Blank and zero-width space, with a short note on what each one is for.

Second, it reveals hidden characters in any text you paste, such as zero-width spaces, byte order marks, direction marks, soft hyphens and non-breaking spaces, and removes them while keeping the joiners that emoji and some languages need.

What you can use it for

Blank names

Make an empty-looking name in games and apps that do not allow blank names.

Spacing in bios and posts

Add blank lines or extra space where apps trim normal spaces.

Fixing broken text

Find out why a password, code snippet, formula or search does not work after copying.

Cleaning data

Remove hidden characters from names, emails or product codes before importing them.

Security checks

Spot right-to-left override tricks that make file names or links look different from what they are.

Step-by-step tutorial: how to use Invisible Character

  1. Choose how many

    Set How many to copy, for example 3 for a longer blank.

  2. Copy a character

    Press Copy on the card you need. The character is on your clipboard.

  3. Paste it

    Paste into the name field, message or bio. If the app removes it, try another blank character.

  4. Check text

    Paste any text into Text to check. Hidden characters show as red labels, special spaces as orange labels, and kept joiners in grey.

  5. See the summary

    The table lists every hidden character found, with its code, name and count.

  6. Clean it

    Press Remove hidden characters. Special spaces become normal spaces unless you untick that option. Then press Copy cleaned text.

Features

  • 18 ready-to-copy charactersBlank fillers, zero-width characters and every common space, each with its code and HTML code.
  • Detects over 100 kindsControl characters, format characters, direction marks, variation selectors, tag characters, fillers and all special spaces.
  • Keeps what mattersJoiners inside emoji like 👨‍👩‍👧 and flags, and joiners in Persian, Arabic and Indic words, are kept by default.
  • Visible markersSee exactly where each hidden character sits in your text.
  • Large textChecks and cleans texts of a megabyte or more in about a second.

A password that will not work

A password copied from a chat works when typed but not when pasted. Paste it into Text to check: a red ZWSP label shows a zero-width space at the end. Press Remove hidden characters, copy the cleaned text and the password works.

Tips and tricks

  • Hangul Filler is the most widely accepted blank character for names.
  • Some apps block blank names on purpose; if all characters are removed, the app does not allow it.
  • Keep Turn special spaces into normal spaces ticked when cleaning data for spreadsheets or code.
  • Untick Keep joiners inside emoji only if you want emoji sequences split into single emoji.

Problems and how to fix them

The blank character shows as a box

Some fonts draw a box for certain fillers. Try Braille Pattern Blank or Hangul Filler instead.

The app removed my blank name

The app trims or blocks that character. Try another one, or combine two different blanks.

Persian or Hindi text changed after cleaning

Make sure Keep joiners inside Persian, Arabic and Indic words is ticked, then paste the original text again.

Questions and answers

Which invisible character works for blank names?

Hangul Filler (U+3164) and Braille Pattern Blank (U+2800) work in most apps and games. Apps can change their rules, so if one is removed, try another.

Why does my text have hidden characters?

They come along when copying from web pages, PDFs, chat apps and word processors. They can break passwords, code, search and spreadsheets without being visible.

Will cleaning break emoji or other languages?

No. By default, joiners inside emoji like 👨‍👩‍👧 and in Persian, Arabic and Indic words are kept. You can change that with the options.

Is my text sent anywhere?

No. Everything happens in your browser.
