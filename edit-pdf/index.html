How to use Edit PDF Text

  1. Choose a PDF.
  2. Click the line of text you want to change and type the new text.
  3. Use the arrows to move between pages.
  4. Click Save edited PDF, then Download.

Questions and answers

Does the new text use the same font?

When the PDF carries its own font and that font contains every letter you typed, yes: the new text is written in that exact font. PDFs usually store only the letters they already use, so if you type a letter that appears nowhere else in that font, the closest standard font (Helvetica, Times or Courier, with matching bold and italic) is used instead. The tool tells you how many changes used each.

How does it change the text?

It paints over the old line with the page colour behind it and writes your new text in the same place, size and colour.

Can I edit a scanned PDF?

No. A scan is a picture of a page, so there is no text to click. Use the Image Text Editor on a page saved as a picture instead.

Can I move text or change its size?

Not yet. You can replace or delete a line, and the new text keeps the position and size of the old one.

Is my PDF uploaded?

No. The file is opened and saved on your own device.
