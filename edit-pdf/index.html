What is Edit PDF Text?

Edit PDF Text lets you change words that are already in a PDF. The page is shown on screen with each line of text inside a blue box. You click a box, type the new text, and save a new PDF with your changes.

It is made for small fixes: a typo, a wrong date, a misspelled name, an old phone number or a price. It takes the old words out of the page and writes your new text in the same place, size and color. Where the PDF holds the letters you need, it reuses the PDF’s own font so the change blends in.

If a page is a scan, the tool tries to read the English text from the picture so you can still click and change lines. Everything runs in your browser, and the file is not uploaded.

What you can use it for

Fix a typo

Correct a spelling mistake in a finished PDF when you no longer have the original Word file.

Update a date or number

Change the date, invoice number or amount on a document you reuse.

Correct a name or address

Fix a misspelled name or an old address on a letter or certificate draft.

Remove a line

Clear the text of a line completely to blank it out on the page.

Change text on a scanned page

On a scanned English page, the tool reads the text so you can change a line, written in a standard font.

Step-by-step tutorial: how to use Edit PDF Text

  1. Choose your PDF

    Click "Click or drop a PDF here" or drag a PDF onto the box. The editor opens and shows page 1. Above the page you see "Page 1 of N", two arrow buttons and the counter "No changes yet".

  2. Find the line you want to change

    Each line or run of text has a blue box over it. Use the "‹" and "›" buttons to move to other pages. A note above the page tells you what to do, or tells you if the page is a scan or has no editable text.

  3. Click the line

    Click or tap a blue box, or select it with the keyboard and press Enter. An edit bar appears below the page with the current text already selected in the input box.

  4. Type the new text

    Type your new text. The page updates as you type, so you can see how it fits. If the new text is longer than the line, a red note warns that it may run into nearby text. The counter above the page changes to "1 line changed", "2 lines changed" and so on. To clear a line completely, delete all its text.

  5. Finish or undo the line

    Press "Done" or the Enter key to close the edit bar. Press "Undo" to put that line back to its original text. You can then click another blue box.

  6. Edit other pages

    Move between pages with the arrows. Your changes on every page are kept until you save.

  7. Click "Save edited PDF"

    The button becomes active once at least one line is changed. A message tells you how many changes were saved and whether they used the PDF’s own font or the closest standard font. If an old line could only be covered over instead of taken out, the message says so.

  8. Download

    Click "Download PDF". The new file is named like letter-edited.pdf. Your original file is not changed.

Features

  • Click-to-edit linesEvery line of real text gets its own clickable blue box.
  • Keeps the original font when possibleIf the PDF carries its own font and that font has every letter you type, your text is written in that same font.
  • Smart standard font fallbackOtherwise the closest standard font is used: Helvetica, Times or Courier, with matching bold and italic.
  • Matches color and positionThe tool samples the page to find the background and text colors, and writes the new text at the same spot and size.
  • Reads scanned pagesOn scanned pages with English text, built-in OCR finds the lines so you can edit them. A progress bar shows the reading progress.
  • Multi-page editingChange lines on several pages and save them all in one file.
  • Live counter and undoSee how many lines you changed, and undo any single line.

Worked example: fixing a date on a letter

Nadia has a 2-page letter.pdf where page 1 says "Date: 3 March 2025" but it should be 2026. She loads the file, clicks the blue box around that line and changes 2025 to 2026. The counter shows "1 line changed". She clicks "Done", then "Save edited PDF". The message says the change was saved in the original font, because all the digits she typed already exist in the PDF’s font. She downloads letter-edited.pdf.

Tips and tricks

  • Keep new text about the same length as the old text. Longer text is not wrapped onto a new line, so it can run into words further along the line. A red note warns you while you type.
  • Each blue box is one run of text, which may be a whole line or just part of it. Edit the box that holds the words you want.
  • Usually the old words are taken out of the file, so they cannot be copied or searched. Sometimes the PDF stores a line in a way the tool cannot safely split (for example, when the line shares one piece of text with other words, or on a scanned page). Then the old line is only covered over and the save message tells you. Do not rely on this tool to hide private information: check the result by searching it for the old words.
  • If the page background has a pattern or a photo, the cover patch is a flat color and may be visible. Plain white pages give the best result.
  • Rotated or mirrored text cannot be edited, and scan reading only works for English text on pages that are not rotated.
  • Open the downloaded file and check every change before you send it.

Problems and how to fix them

The note says the text on this page is turned sideways or upside down

The page or its text is rotated, and only upright text can be edited. Straighten the page with Rotate PDF first, then edit the new file.

The note says "This page has no text that can be edited"

The page has no real text and is rotated, so it cannot be read. Try straightening it with Rotate PDF first, then edit the new file.

The note says "No text could be read on this page"

The scan may be handwriting, a photo, a language other than English, or too blurry. This tool cannot edit that page.

The note says a line was added as a picture of the text

The PDF’s own font does not have those letters, and neither do the standard fonts (for example Arabic, Chinese or emoji). The line still looks right, but it is a picture, so it cannot be selected or searched.

The new text is in a slightly different font

The PDF did not contain every letter you typed in its own font, so the closest standard font was used. Try wording that reuses letters already in the line, or accept the close match.

A message says "This PDF is password protected"

Remove the password in a PDF reader that knows it, save a copy, and edit that copy.

The save message says an old line was only covered over

The new text is in place, but the old words are still hidden in the file and can be found by copying or searching. If that matters, check the file before you share it.

Questions and answers

Does the new text use the same font?

When the PDF carries its own font and that font contains every letter you typed, yes: the new text is written in that exact font. PDFs usually store only the letters they already use, so if you type a letter that appears nowhere else in that font, the closest standard font (Helvetica, Times or Courier, with matching bold and italic) is used instead. The tool tells you how many changes used each.

How does it change the text?

It takes the old words out of the page and writes your new text in the same place, size and colour. When a line is stored in a way that cannot be safely split, the old line is painted over with the page colour instead, and the tool tells you that it is only covered.

Can I edit a scanned PDF?

Often, yes. When a page has no real text, the tool reads the scan with text recognition (English, upright pages) so you can click the lines. Results depend on how clear the scan is; for a single photo or picture, the Image Text Editor gives you more control.

Can I move text or change its size?

Not yet. You can replace or delete a line, and the new text keeps the position and size of the old one.

Is my PDF uploaded?

No. The file is opened and saved on your own device.
