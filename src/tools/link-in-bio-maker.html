How to put your page online for free

You downloaded one file called index.html. Any free static host can serve it. Then copy your new address into "Your page's web address" above (for the QR code) and paste it into your social profiles.

Netlify Drop (easiest, no code)

  1. Put index.html alone in a new folder.
  2. Open app.netlify.com/drop and drag the folder onto the page.
  3. Sign up (free) to keep the site, then change its name under Site settings to get yourname.netlify.app.

GitHub Pages

  1. Create a free GitHub account and a new public repository, for example "links".
  2. Choose "Add file", then "Upload files", and upload index.html. Commit.
  3. Open Settings, then Pages, pick the main branch and Save. After a minute your page is at yourname.github.io/links.

Cloudflare Pages

  1. Create a free Cloudflare account and open Workers & Pages.
  2. Create a Pages project and choose "Upload assets" (direct upload).
  3. Name the project, upload the folder with index.html and deploy. Your page is at name.pages.dev.

To change the page later, edit it here, download again and upload the new index.html the same way.
