What is Character Map?

The Character Map shows every character in Unicode 15.1, about 150,000 letters, symbols, emoji and marks, grouped in their Unicode blocks.

Search by name, code or HTML entity, then copy the character or any of its codes: code point, decimal, HTML named and numeric entities, CSS, JavaScript and Python escapes, UTF-8 and UTF-16 bytes and URL encoding.

What you can use it for

Symbols for documents

Find arrows, check marks, stars, currency and maths signs to paste into documents or posts.

Web development

Get the HTML entity or CSS escape for a symbol in your code.

Foreign letters

Find accented letters or letters from other alphabets you cannot type.

Debugging text

Paste a strange character to see exactly what it is and its UTF-8 bytes.

Design

Browse blocks like Box Drawing, Geometric Shapes and Dingbats for ideas.

Step-by-step tutorial: how to use Character Map

  1. Search or browse

    Type a word such as arrow or heart, a code such as U+2713, or pick a block. Quick buttons open popular blocks.

  2. Look at the grid

    Characters appear as buttons. Marks show on a dotted circle, and invisible characters as a small symbol.

  3. Select a character

    Click one to see its official name, block and all its codes.

  4. Copy what you need

    Press Copy next to the character or the code you want.

  5. Collect several

    Press Add or double-click characters to collect them in Your collected characters, then copy them all.

  6. Browse large blocks

    Big blocks such as CJK ideographs are split into pages of 512 with Previous and Next.

Features

  • Full Unicode 15.1All 328 blocks with official names, including algorithmic names for Hangul syllables and CJK ideographs.
  • Search by name or codeWords, U+ codes, hex, &#…; numbers and &name; entities all work.
  • Every code formatHTML, CSS, JavaScript, Python, UTF-8, UTF-16 and URL encoding.
  • HTML entity namesShows the named entity, such as &eacute;, when one exists.
  • Collect and copyBuild a string of characters and copy it in one go.

Finding a check mark for HTML

Type check in the search box. Choose CHECK MARK (U+2713). The codes show &#10003;, &#x2713;, the named entity &check;, CSS \2713 and JavaScript \u2713. Press Copy next to the one your page needs.

Tips and tricks

  • Search with English words from the official names, such as left arrow, not with descriptions like back.
  • Paste a mysterious character into the search box to identify it.
  • If a character shows as an empty box, your device lacks a font for it; the code is still right.
  • Use Copy on the Character row to copy the symbol itself.

Problems and how to fix them

Search finds nothing

Try a single English word from the Unicode name, such as star, arrow or check, or search by code.

The character list does not load

It downloads once (about 140 KB). Check your connection and reload the page.

Emoji look different elsewhere

Each device and app draws emoji in its own style; the code point is the same.

Questions and answers

What can I search for?

Words from the official Unicode name (heart, arrow, check), a code point like U+2713 or 2713, an HTML entity like &check; or &#10003;, or characters you paste.

Why do some characters show as empty boxes?

Your device has no font with that character. The character is still correct and will show on devices that have a suitable font.

What is the difference between the HTML codes?

Named entities like &eacute; are easy to read; numeric ones like &#233; or &#xE9; work for every character.

Which Unicode version is used?

Unicode 15.1 names and blocks.
