What is Label Sheet Maker?

The Label Sheet Maker prints text on sheets of sticky labels. It places each label with exact measurements so the text lands inside the labels on your sheet.

It has common A4 and US Letter layouts for address labels, name badges and small labels, and a custom option for any sheet. Text is sized to fit each label and centred top to bottom.

Type labels with an empty line between them, repeat one label across the sheet, or import addresses from a CSV file with your own layout. Start at any position and print copies of each label.

Step-by-step tutorial: how to use Label Sheet Maker

  1. Pick the sheet

    Choose the layout that matches the size on your label pack, or Custom size.

  2. Add your labels

    Type them with an empty line between labels, or use Same on every label.

  3. Or import a CSV

    Choose the file, then write the layout with {column names}.

  4. Set copies and start

    Copies of each label, and the first empty label on a used sheet.

  5. Adjust the text

    Largest size, alignment, space inside and a bold first line.

  6. Test print

    Tick "Print label outlines" and print one page on plain paper. Hold it over a label sheet to check.

  7. Print

    Untick outlines, download the PDF and print at 100% on the label sheet.

Worked example: card addresses

Priya exports her contacts as a CSV with Name, Street, City and Postcode columns, chooses "A4: 21 labels", imports the file and writes "{Name}\n{Street}\n{City} {Postcode}". 47 labels fill 3 sheets. Her first sheet already has 5 labels used, so she sets Start at label number to 6.

Tips and tricks

  • Always test on plain paper first and hold it against a label sheet.
  • Print at 100% or "Actual size", never "Fit to page".
  • Feed one label sheet at a time if your printer jams.
  • Use the bold first line for names.
  • Save your spreadsheet as CSV UTF-8 to keep accented letters.

Problems and how to fix them

Text is a few millimetres off

Check "Actual size" printing, then use Move everything right or down.

"There is no column called…"

Use the column names exactly as in the first row of the CSV, in curly brackets.

"Not a CSV file"

Save your Excel or Sheets file as CSV first.

Some text is cut off

Lower the text size, shorten lines or use a bigger label.

Accented letters look wrong

Save the CSV as UTF-8.

Questions and answers

Which label sheets work?

Common layouts such as A4 21 per sheet (63.5 × 38.1 mm), 14, 24, 8, 30 and 65 per sheet, and US Letter 30 per sheet (2⅝ × 1 in), 20, 14, 10 and 80 per sheet. For others, choose Custom size and type the measurements from the box.

How do I print addresses from a spreadsheet?

Save the spreadsheet as CSV, choose "From a spreadsheet (CSV)" and pick the file. Then write the layout using column names in curly brackets, like {Name} and {City}.

Can I use a sheet that is partly used?

Yes. Set "Start at label number" to the first empty label. Labels are counted across, then down.

My print is a little off. What can I do?

Print at 100% ("Actual size"), not "Fit to page". If it is still off, move everything right or down by a millimetre or two and print a test on plain paper.

Can I write in other languages?

Yes, any language, including Arabic and Hebrew right to left.
