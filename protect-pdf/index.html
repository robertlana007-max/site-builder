What is Protect PDF?

Protect PDF adds a password to a PDF, so nobody can open it without typing that password. It uses AES 256-bit encryption, the strongest encryption built into the PDF standard.

You can also add restrictions that stop people from printing the file, copying its text or changing its pages. This is useful for contracts, payslips, medical letters, school results and anything else you send by email.

The encryption is done in your browser by qpdf, a trusted open source PDF program running on your device. The PDF and the password are never uploaded.

What you can use it for

Email private documents

Lock payslips, contracts or medical letters before you send them, and share the password another way.

Protect client files

Accountants, lawyers and teachers can lock reports and results for each person.

Stop copying or printing

Share a document people can read but not easily copy or print.

Store files safely

Keep scanned IDs and certificates encrypted on a shared drive or phone.

Step-by-step tutorial: how to use Protect PDF

  1. Add your PDF

    Click the box that says "Click or drop a PDF here", or drag the file onto it.

  2. Choose a password

    Type it in "Password to open the PDF". A bar shows how strong it is: aim for Good or Strong.

  3. Type it again

    Type the same password in "Type the password again". Use "Show" to check both.

  4. Add restrictions if you want

    Open "Restrictions (optional)" and untick what people may not do: printing, copying, editing, or comments and forms. You can set an owner password, or leave it empty to get a random one.

  5. Pick the encryption

    Keep "AES 256-bit" unless the file must open in very old PDF readers.

  6. Protect and download

    Click "Protect PDF", then "Download protected PDF". The new file ends in -protected.pdf.

  • AES 256-bit encryptionStrong, modern encryption that every current PDF reader supports.

Worked example: sending a contract

Luca has rental-contract.pdf to email to a new tenant. He drops it in, types the password Blue-Harbour-2026 twice and sees "Strong." under the bar. He opens Restrictions and unticks "Allow editing pages". He clicks Protect PDF, downloads rental-contract-protected.pdf, attaches it to the email and sends the password by text message.

Tips and tricks

  • Use a long password, such as three words with a number and a symbol.
  • Send the password separately, for example by phone or text message, not in the same email.
  • Keep an unprotected copy for yourself; a lost password cannot be recovered.
  • Restrictions alone do not hide the content. Use an open password for private files.
  • If the PDF already has a password, remove it first with Unlock PDF.

Problems and how to fix them

The message says the PDF already has a password

Remove the old password with Unlock PDF, then add the new one here.

The two passwords are not the same

Type both again carefully, or click Show to compare them.

AES 128-bit refuses my password

For 128-bit encryption only plain letters, numbers and keyboard symbols work. Choose AES 256-bit for passwords with accents or other alphabets.

Someone cannot open the file

Make sure they type the password exactly, including capital letters. Very old readers may need AES 128-bit.

Questions and answers

How strong is the protection?

The PDF is encrypted with AES 256-bit, the strongest standard PDF encryption. A long password with letters, numbers and symbols is very hard to guess.

Will the PDF open on any device?

Yes. Adobe Reader, browsers, phones and Mac Preview all open AES-256 PDFs after you type the password. Choose AES 128-bit only for very old readers.

Is my password uploaded?

No. The password and the file never leave your browser.

What if I forget the password?

There is no way to recover it, not even for us. Keep a copy of the original file or write the password down somewhere safe.

What is the owner password?

It is a second password that lets you change or remove the restrictions later. If you leave it empty, a random one is made and shown to you.

Do restrictions work everywhere?

Most readers respect them, but some programs ignore them. Only the open password truly keeps people out.
