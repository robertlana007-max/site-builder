How to use the image resizer

  1. Choose an image.
  2. Type the new width or height. With aspect ratio locked, the other side updates by itself.
  3. Pick PNG, JPG or WebP.
  4. Click Resize image, then Download.

Frequently asked questions

Will resizing reduce quality?

Making an image smaller keeps it sharp. Making it larger than the original will look soft, because the extra pixels have to be invented.

What does "keep aspect ratio" do?

It keeps the shape of the picture the same so that people and objects are not stretched or squashed.

Is there a size limit?

Output can be up to 10,000 pixels on each side. Very large images may be slow on older phones.
