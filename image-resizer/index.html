What is Image Resizer?

The Image Resizer changes the width and height of a picture in pixels. You can make a large photo smaller, make a small graphic bigger, or set an exact size that a website, form or app asks for.

It helps people who need a picture at a fixed size: a profile photo, a product image for a shop, a banner, a thumbnail for a video or a document photo for an online application. You can keep the original shape, or type any width and height you like, and save the result as PNG, JPG or WebP.

The picture is resized in your own browser, so nothing is uploaded and your files stay private.

What you can use it for

Profile and avatar photos

Many sites want a square image such as 400 × 400 px. Turn off the aspect lock and type the exact size, or crop first and then resize.

Online application photos

Government and job forms often ask for a photo with a given width and height. Type those numbers and download the file.

Product images for a shop

Make every product photo the same width, for example 1000 px, so your shop looks neat and loads fast.

Thumbnails and banners

Create a small preview image or a wide header image at the size your platform recommends.

Make a file smaller

Reducing the pixel size is the strongest way to reduce file size before sending a photo by email or chat.

Step-by-step tutorial: how to use Image Resizer

  1. Open your picture

    Click the box "Click or drop an image here" or drag a file onto it. Under the buttons you will see the original size, for example "Original size: 3024 × 4032 px", and the width and height boxes are filled in with those numbers.

  2. Decide on "Keep aspect ratio"

    This box is ticked by default. While it is ticked, changing the width also changes the height (and the other way round) so the picture keeps its shape. Untick it only if you need an exact size that has a different shape, and accept that the picture may look stretched.

  3. Type the new width or height

    Enter a number in "Width (px)" or "Height (px)". With the lock on, the other box updates as you type. Both numbers must be between 1 and 10000.

  4. Pick the output format

    In "Output format" choose PNG, JPG or WebP. PNG keeps transparency and sharp edges. JPG gives small files for photos. WebP is small and keeps transparency, but some older programs cannot open it.

  5. Click "Resize image"

    The tool draws the picture at the new size with high-quality smoothing. A green message shows the new size and the file size, for example "Done: 1200 × 1600 px, 310 KB", and a preview appears below.

  6. Download the new file

    Click "Download". The file name gets the new size added, for example photo-1200x1600.jpg. Your original file is not changed, so you can resize it again with other numbers.

Features

  • Aspect ratio lockKeeps the picture’s shape by working out the second dimension for you.
  • Exact pixel sizesType any width and height from 1 to 10000 px.
  • Three output formatsSave as PNG, JPG or WebP, whatever the input format was.
  • High-quality scalingUses the browser’s best smoothing so shrunk photos stay clean.
  • Clear file namesThe download name includes the new size, so you never mix up versions.
  • Instant previewSee the resized picture on the page before you download it.

Worked example: a phone photo for a website

Your phone photo is 3024 × 4032 px and you need it 1200 px wide. Leave "Keep aspect ratio" ticked and type 1200 in Width. The Height box changes to 1600, because 1200 × 4032 ÷ 3024 = 1600. You choose JPG, click "Resize image", and the message reads something like "Done: 1200 × 1600 px, 300 KB". Click "Download" to get photo-1200x1600.jpg.

Tips and tricks

  • Making a small picture much bigger cannot add real detail. It will look soft. Start from the largest original you have.
  • If a site asks for a square image and your photo is not square, the picture will look squashed. Crop it to a square first, then resize.
  • For photos, JPG keeps the file small. For logos, screenshots and pictures with transparent parts, use PNG.
  • To fit a size limit in KB, resize here first, then use the Image Compressor if the file is still too big.
  • You can type in the Height box instead of Width. With the lock on, the width follows.

Problems and how to fix them

The picture looks stretched or squashed

"Keep aspect ratio" was off and the numbers do not match the picture’s shape. Tick the box, type one dimension again, and resize.

"Enter a width and height between 1 and 10000 px"

One box is empty, zero, or above 10000. Fix the numbers and click "Resize image" again.

The background turned white

JPG has no transparency, so see-through parts are filled with white. Choose PNG or WebP to keep them.

The "Resize image" button is grey

No picture has been loaded yet, or the file could not be read. Open a normal JPG, PNG or WebP image first.

"Your browser could not encode this format"

Your browser cannot save WebP. Pick PNG or JPG instead.

Questions and answers

Will resizing reduce quality?

Making an image smaller keeps it sharp. Making it larger than the original will look soft, because the extra pixels have to be invented.

What does "keep aspect ratio" do?

It keeps the shape of the picture the same so that people and objects are not stretched or squashed.

Is there a size limit?

Output can be up to 10,000 pixels on each side. Very large images may be slow on older phones.
