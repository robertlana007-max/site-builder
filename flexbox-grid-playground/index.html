What is Flexbox and Grid Playground?
The Flexbox and Grid Playground lets you try every main CSS flexbox and grid property on real boxes and see the layout change instantly. When the layout looks right, copy the CSS and HTML.
It is made for people learning CSS layout, and for developers who want to check how justify-content, align-items, flex-grow or grid-template-columns behave before writing code.
Nothing is uploaded; it all runs in your browser.


What you can use it for
Learn flexbox
Change one property at a time and watch how the boxes move.
Plan a navigation bar
Use flex with justify-content: space-between to push items to the edges.
Build a card grid
Use grid-template-columns with repeat(auto-fill, minmax(100px, 1fr)) and resize the area to see it respond.
Debug a layout
Copy your values into the playground to find out which property causes a problem.
Teach CSS
Show students in class how each value changes a layout.


Step-by-step tutorial: how to use Flexbox and Grid Playground
  1. Choose Flexbox or Grid
    Use the tabs at the top. The dashed area is the container and the colored boxes are its items.
  2. Change container settings
    Under Container, pick values such as flex-direction, justify-content and align-items, or type grid-template-columns, rows and gap. The preview updates immediately.
  3. Edit one box
    Click a box to select it (it gets a dark outline). Under Box, set flex-grow, flex-shrink, flex-basis, align-self and order, or for grid, grid-column, grid-row and self alignment.
  4. Add and remove boxes
    Use Add box and Remove box to see how wrapping and auto-placement work with more or fewer items. Some boxes are taller on purpose so alignment is visible.
  5. Resize the container
    Drag the bottom-right corner of the dashed area to see how the layout reacts to less space.
  6. Copy the code
    Copy CSS gives the container rule and a rule for each changed box. Copy HTML gives matching markup.


Features
  • Flexbox and GridAll common container and item properties for both layout systems.
  • Per-item settingsSelect any box to set its own flex or grid placement.
  • SuggestionsText fields offer common values like repeat(3, 1fr) or span 2.
  • Resizable previewDrag the container corner to test responsive behavior.
  • Minimal CSSOnly values that differ from the defaults are written.
  • Up to 24 boxesEnough to test wrapping and grid auto-placement.


Worked example: a header bar
In Flexbox, set justify-content to space-between and align-items to center. Box 1 moves to the left edge, box 5 to the right edge and the rest spread evenly. Click box 2 and set flex-grow to 1: it now takes up the spare space, like a search field in a header. Copy CSS gives .container { display: flex; justify-content: space-between; align-items: center; gap: 10px; } and .item:nth-child(2) { flex-grow: 1; }.


Tips and tricks
  • justify-content works along the main axis (a row by default) and align-items across it; switching flex-direction to column swaps them.
  • align-content only has an effect when items wrap onto more than one line.
  • In grid, 1 / -1 in grid-column makes an item span every column.
  • The fr unit shares out leftover space, so 1fr 2fr gives the second column twice as much.
  • Use gap instead of margins between items; it does not add space at the outer edges.


Problems and how to fix them
justify-content does nothing
There is no spare space: the boxes already fill the row, or one has flex-grow. Make the container wider or remove flex-grow.
align-items: center does not center vertically
The container must be taller than its items. Drag the container corner down or give it a height.
My grid value is ignored
An invalid value, such as a missing bracket, is marked in red and left out of the CSS code. Check the spelling, for example repeat(3, 1fr).
The copied CSS uses .container and .item
Rename these classes to match your own HTML, or use Copy HTML to get matching markup.



Questions and answers


What is the difference between flexbox and grid?
Flexbox lays items out in one direction, a row or a column. Grid places items in rows and columns at the same time.
Why does align-content not change anything?
It only affects multiple lines, so set flex-wrap to wrap and add enough boxes to fill more than one row.
Can I type my own values?
Yes. Text fields such as gap, flex-basis and grid-template-columns accept any valid CSS value.
Is the preview the same as a real browser?
Yes. The boxes are real HTML elements laid out by your browser using the CSS shown.
