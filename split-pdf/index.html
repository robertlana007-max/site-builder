How to use Split PDF

  1. Choose a PDF.
  2. Type the pages you want, such as 1-3, 5.
  3. Choose one PDF or a separate PDF for every page.
  4. Click Split PDF, then Download.
help.hlp

Questions people ask

How do I write page ranges?

Use commas between pages and a hyphen for a range. For example 1-3, 5 means pages 1, 2, 3 and 5.

Can I change the page order?

Yes. Pages come out in the order you type them, so 5, 1-3 puts page 5 first.

What do I get when I split every page?

A ZIP file containing one PDF for each page you listed.
