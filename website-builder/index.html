    What is Website Builder?

    The Website Builder makes a simple one-page website for a shop, portfolio or event without code. Build it from blocks: a hero with a big title, about, services or a price list, gallery, testimonials, FAQ, opening hours, a map link and contact buttons.

    Choose one of 11 themes, heading and text fonts and an accent colour, reorder blocks by dragging or with the arrows, and check the result in a live preview at desktop, tablet and phone sizes.

    Download one index.html file or a ZIP with an images folder, ready for free hosts such as GitHub Pages, Netlify or Cloudflare Pages. Pages include search engine tags, are responsive and come with built-in accessibility checks. Everything happens in your browser.

    What you can use it for

    Local shops and cafés

    Prices, opening hours, a map link and a call button.

    Portfolios

    An about section, a gallery of your work and testimonials.

    Events

    Programme, FAQ, venue and how to get in touch.

    Freelancers and tutors

    Services with prices and a contact block.

    Clubs and community groups

    Who you are, when you meet and how to join.

    Step-by-step tutorial: how to use Website Builder

    1. Name your site

      Type the site name, choose the kind of site and write a one-sentence description for search engines.

    2. Pick a design

      Choose a theme, then change the heading font, text font, accent colour or corners if you like.

    3. Fill in the blocks

      Tap a block's name to open it and type your text. The example blocks show what goes where.

    4. Add pictures and describe them

      Choose a picture for the hero, about or gallery blocks. Pictures are shrunk automatically. Type a short description (alt text) for each, or tick Decorative only.

    5. Add, remove and reorder blocks

      Pick a block type and press Add block. Drag the handle or use the arrows to change the order.

    6. Check the preview

      Switch between Desktop, Tablet and Phone, and read the Accessibility and SEO check list.

    7. Export

      Press Download index.html for one file, or Download ZIP for index.html plus an images folder. Upload it to any free host.

    8. Save your project

      Save project (JSON) keeps a copy you can open later to edit the site.

    Worked example: a bakery

    Lina's Bakery uses the Warm café theme. The hero says "Fresh bread every morning" with a button that jumps to the price list. The services block lists Sourdough loaf 4.50 and Birthday cake from 28.00, the hours block lists the week with Sunday closed, and the map block turns "12 Market Street, Old Town" into an Open in maps button. After adding a hero photo with the description "Fresh loaves on a wooden shelf", Lina downloads the ZIP (about 300 KB) and uploads the folder to Netlify Drop.

    Tips and tricks

    • Write the description like a shop sign: what you offer and where, in about 120 to 160 characters.
    • Describe every photo in a few words, as you would to a friend on the phone.
    • Fill in the web address once your site is online, then export again so search engines and social apps get the right links and preview picture.
    • Use the ZIP for sites with many photos: pictures load separately and the page appears faster.
    • Type prices exactly as you want them shown, with your own currency.

    Problems and how to fix them

    My pictures are gone after reloading

    Very large galleries can be too big for the browser's storage. Press Save project to keep a copy, and open it again later.

    The export asks about missing descriptions

    Some pictures have no alt text. Add a short description or tick Decorative only, or choose OK to export anyway.

    A button is missing on the page

    Buttons need both text and a working link (a web address or a section link like #contact).

    Fonts look different on my phone

    System fonts change slightly between devices. Choose one of the bundled heading fonts for an identical look everywhere.

    Questions and answers

    Do I need to know how to code?

    No. You type into simple forms and the tool writes clean, responsive HTML for you.

    Where can I host the website?

    Anywhere that serves static files, including free GitHub Pages, Netlify and Cloudflare Pages. Upload index.html, or unzip the ZIP and upload the folder.

    Is the website good for search engines?

    Pages include a title, description, language, canonical link, social sharing tags and, for local businesses, structured data with your contact details.

    Is the website accessible?

    Yes. The checker asks for picture descriptions, checks colour contrast, keeps one main heading and adds a skip link, and links use a readable shade of your accent colour.

    Should I choose one file or the ZIP?

    One file is easiest to upload. The ZIP keeps pictures as separate files, so the page loads faster and social apps can show your main picture.

    Can I edit the site later?

    Yes. It is kept in this browser, and Save project (JSON) gives you a file you can open again on any device.
