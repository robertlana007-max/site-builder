What is Password Generator?

The Password Generator creates strong random passwords. You choose the length (6 to 64 characters) and which kinds of characters to use: capital letters, small letters, numbers and symbols. A meter and a label tell you how strong the password is, measured in bits of entropy.

It is for anyone who needs a new password for an email account, a bank, a Wi-Fi network, a work system or a new app, and wants something that cannot be guessed. A random password is much safer than a word, a name or a birthday, and it is best stored in a password manager.

Passwords are made in your browser with its secure random number generator and are never sent or saved anywhere.

What you can use it for

New online accounts

Create a unique password for each website, so one leak does not open your other accounts.

Change a weak or leaked password

Replace an old password that was reused or appeared in a data breach.

Wi-Fi and router passwords

Make a long password for your home network. Turn on "Skip look-alikes" so guests can type it without mistakes.

Work and admin accounts

Generate long passwords that meet strict company rules for capitals, numbers and symbols.

Temporary passwords

Give a new user a random first password that they change after logging in.

Step-by-step tutorial: how to use Password Generator

  1. See the first password

    When the page opens, a 16-character password is already shown at the top, using all four character types. Below it, a meter and a line such as "Very strong · about 103 bits of entropy" show its strength.

  2. Set the length

    Drag the "Length" slider from 6 to 64. The number next to it shows the length, and a new password is made each time you move it. 16 or more is a good choice for most accounts.

  3. Choose character types

    Tick or untick "Uppercase (A-Z)", "Lowercase (a-z)", "Numbers (0-9)" and "Symbols (!@#$)". Every type you tick is guaranteed to appear at least once. If you untick all of them, Lowercase is turned back on, because a password needs at least one type.

  4. Skip look-alike characters

    Tick "Skip look-alikes (0 O 1 l I)" to leave out the digit zero, capital O, the digit one, small L and capital I. This makes a password easier to read and type by hand, with only a small loss of strength.

  5. Get another one

    Click "Generate new" for a fresh password with the same settings. Repeat until you get one you like.

  6. Copy and store it

    Click "Copy" and paste the password into the sign-up form and into your password manager straight away. The tool does not keep it, so once you leave the page it is gone.

Features

  • Secure randomnessUses the browser’s crypto random generator with no bias, the same kind of source used for encryption keys.
  • Length 6 to 64Make short PINs or very long passphrases with one slider.
  • Four character setsUppercase, lowercase, numbers and 23 symbols, mixed in any combination.
  • At least one of eachEvery chosen type appears at least once, so the password meets most website rules.
  • Look-alike filterRemoves 0, O, 1, l and I to avoid reading mistakes.
  • Strength meterShows a bar, a label (Weak, Fair, Strong or Very strong) and the estimated bits of entropy.

Worked example: how the strength is calculated

With all four types ticked, the tool picks from 85 characters (26 capitals, 26 small letters, 10 digits and 23 symbols). Each character adds log2(85), about 6.4 bits. A 16-character password therefore has about 16 × 6.4 = 103 bits, so it is labelled "Very strong". If you use only small letters and numbers (36 characters, about 5.2 bits each) with a length of 12, you get about 62 bits, which is labelled "Fair". The labels are: under 50 bits Weak, 50 to 74 Fair, 75 to 99 Strong, and 100 or more Very strong.

Tips and tricks

  • Use a different password for every account. A password manager can remember them all for you.
  • Length adds more strength than symbols. A 20-character password of letters and numbers beats a 10-character one with symbols.
  • If a site does not accept some symbols, untick "Symbols" and add a few extra characters of length instead.
  • Turn on two-factor authentication as well, because even a perfect password can be stolen by a fake login page.
  • Never send a new password by plain email or chat if you can avoid it.

Problems and how to fix them

The website says my password is invalid

Some sites limit length or ban certain symbols. Shorten the length or untick "Symbols" and generate again.

I unticked every box and Lowercase came back

A password needs at least one character type, so Lowercase is turned on automatically.

"Copy" did not work

Your browser may block the clipboard. Select the password with the mouse and press Ctrl+C (Cmd+C on Mac).

I lost the password after closing the page

Passwords are not saved anywhere by this tool. Use the "Forgot password" link on the website and create a new one, then store it in a password manager this time.

Questions and answers

Is it safe to generate a password online?

This page creates the password inside your browser using the Web Crypto API. Nothing is sent over the internet.

How long should a password be?

Use at least 12 characters for everyday accounts and 16 or more for email, banking and anything important.

How do I remember random passwords?

You should not have to. Store them in a password manager and use a different password on every site.
