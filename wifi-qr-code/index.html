What is Wi-Fi QR Code?

The Wi-Fi QR Code generator makes a QR code that phones scan to join your Wi-Fi without typing the password. Enter the network name, password and security type, and download the code as PNG or SVG, or print a ready-made "Scan to join Wi-Fi" card.

It writes the standard WIFI: text that iPhone and Android cameras understand, and correctly escapes the special characters \ ; , : and " so names and passwords with symbols still work.

Everything is made in your browser. Your Wi-Fi password is never sent anywhere and is not saved on this device.

What you can use it for

Cafés, shops and restaurants

Put a table tent or a sign by the counter so customers can join in one scan.

Holiday rentals and guest rooms

Leave a card for guests instead of a long password on a sticky note.

Home

Stick a card on the fridge so visiting friends and family join easily.

Offices and events

Print the guest network code on badges, welcome packs or slides.

Schools and clinics

Share a guest network at reception without spelling out the password.

Step-by-step tutorial: how to use Wi-Fi QR Code

  1. Type the network name

    Enter the Wi-Fi name (SSID) exactly as it appears in the Wi-Fi list on your phone, including capital letters and spaces.

  2. Choose the security

    Most networks use WPA, WPA2 or WPA3: keep the first option. Choose WEP only for very old routers, or None for an open network with no password.

  3. Type the password

    Enter the password exactly. WPA passwords are 8 to 63 characters. Tick "Hidden network" only if your network does not show up in the Wi-Fi list.

  4. Test the code

    The QR code updates as you type. Point your phone camera at it: the phone should offer to join the network.

  5. Download PNG or SVG

    PNG is a picture for screens and documents; SVG stays sharp at any size for printing and design apps.

  6. Print a card

    Choose the paper: A4 or US Letter sign, A6 card, or a table tent that you fold in half. Change the heading and colour if you like, choose whether to print the name and password as text, then press Make PDF card.

  7. Print at actual size

    Print the PDF at 100%. For a table tent, fold along the dashed line so it stands with the code on both sides.

Features

  • Standard formatWIFI:T:WPA;S:name;P:password;; works with iPhone (iOS 11+) and Android (10+) cameras and most QR apps.
  • Correct escapingBackslash, semicolon, comma, colon and double quote are escaped so tricky passwords still work.
  • Checks your inputWarns about WPA passwords that are too short or long, names over 32 bytes, odd WEP keys and stray spaces.
  • PNG and SVGDownload a crisp PNG or a vector SVG.
  • Printable card PDFA4, US Letter, A6 or a fold-in-half table tent, with a Wi-Fi icon, heading, network name and password.
  • Any languageNetwork names in Arabic, Chinese, Hindi or with emoji print correctly on the card.
  • PrivateThe password is never uploaded or saved.

Worked example: a table tent for a café

Your guest network is called Cafe Guest and the password is sunny;day:42. You type both, keep WPA/WPA2/WPA3, and the code updates. The text inside the code is WIFI:T:WPA;S:Cafe Guest;P:sunny\;day\:42;; because the ; and : in the password are escaped. You scan the screen with your phone and it joins. Then you choose Table tent (A4), set the heading to "Free Wi-Fi", press Make PDF card, print it at 100% and fold it in half for each table.

Tips and tricks

  • Always test the code with a phone before printing many copies.
  • If you change your Wi-Fi password, print new cards: the old code stops working.
  • Untick "Print the network name and password as text" if you do not want the password readable by everyone who walks past.
  • Use a guest network for customers and visitors, not your main network.
  • Print the code at least 3 cm wide so phones can scan it from a normal distance.

Problems and how to fix them

The phone says it cannot join

The name or password does not match exactly. Check capital letters, spaces and the security type, then make the code again.

"WPA passwords are 8 to 63 characters long"

Wi-Fi WPA passwords must have 8 to 63 characters. Check you typed the whole password.

The phone does not react to the code

Make sure the camera's QR scanning is turned on, the code is in focus and well lit, and the print is not too small.

A hidden network does not connect

Some older phones cannot join hidden networks from a QR code. Make the network visible, or type it in by hand.

Questions and answers

Which phones can scan a Wi-Fi QR code?

iPhones from iOS 11 and most Android phones from Android 10 join directly from the camera app. Older phones can use a QR scanner app.

My network uses WPA3. Which option do I choose?

Choose "WPA / WPA2 / WPA3". The code says WPA, and the phone works out the exact version when it connects.

My password has ; or : in it. Will it work?

Yes. Special characters (\ ; , : and ") are escaped in the code as the format requires, so the phone reads the password correctly.

Is my Wi-Fi password saved or uploaded?

No. The code is made in your browser. The network name is remembered on this device for next time, but the password is not.

Can I hide the password on the printed card?

Yes. Untick "Print the network name and password as text" and the card shows only the heading and the QR code.

What is a table tent?

A card you fold in half to stand on a table. The PDF prints the design twice, once upside down, so the code faces both sides after folding.
