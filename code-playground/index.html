What is Code Playground?

The Code Playground is a live HTML, CSS and JavaScript editor. Type code in the three tabs and see the result in a preview below, with a console that shows your console.log() messages and errors.

It is ideal for learning web development, testing a quick idea, making a small demo or sharing a snippet with a friend or colleague, with nothing to install and no account.

Your code runs in a locked-down sandbox that cannot reach this page, your cookies or your saved data. The draft is stored only in this browser, and share links carry the code inside the link.

What you can use it for

Learn HTML, CSS and JavaScript

Change code and see the effect instantly, with errors shown in plain view.

Test a snippet

Paste code from a tutorial or answer and check that it works.

Build a small demo

Make a button, animation or form and download it as a single HTML file.

Share code

Send a link that opens the same code for someone else.

Debug JavaScript

Use the console line to inspect variables of the running page.

Step-by-step tutorial: how to use Code Playground

  1. Write HTML

    The HTML tab holds the page content. You can write just the body content, or a full document with <html> and <head>.

  2. Add CSS and JavaScript

    Switch to the CSS and JS tabs. CSS is added to the page head and JavaScript runs after the HTML has loaded.

  3. Run the code

    With Auto-run ticked, the preview refreshes shortly after you stop typing. Otherwise click Run or press Ctrl+Enter (Cmd+Enter on Mac). Each run starts a fresh preview.

  4. Read the console

    Messages from console.log, console.warn and console.error appear under the preview, along with errors and the line they happened on. Type JavaScript in the line at the bottom and press Enter to run it inside the preview.

  5. Start from a template

    Choose a template such as Click counter, To-do list or Canvas animation to see working examples.

  6. Save, share and download

    Your work is saved in this browser automatically. Share link copies a link with the code inside it. Download HTML saves one standalone file you can open anywhere.

Features

  • Three editors with highlightingSyntax colors, line numbers, bracket matching and auto-closing tags.
  • Safe sandboxThe preview runs without access to this site, its storage or your cookies, and cannot redirect the page.
  • Console with errorsLogs, warnings, errors with line numbers, objects shown readably and a command line.
  • Endless-loop protectionA loop that runs more than 2.5 seconds is stopped so the page does not freeze.
  • Share links without a serverThe code is compressed into the link itself.
  • Download as one HTML fileA clean file without any of the playground's helper code.

Worked example: a click counter

Pick the Click counter template. The HTML has a number and two buttons, the CSS centers a white card, and the JavaScript adds 1 on each click and logs count is 1, count is 2 and so on. Click +1 three times: the console shows three messages. Type n * 10 in the console line and press Enter; it answers 30, read live from the running page. Click Share link to send it, or Download HTML to keep it.

Tips and tricks

  • Use console.log() generously; objects and arrays are shown in a readable form.
  • Untick Auto-run when you write long scripts, so the preview does not restart while you are halfway through a line.
  • Very long share links can be cut off by some chat apps; for bigger projects, download the HTML file instead.
  • Scripts from other websites (for example a library from a CDN) can be added with a <script src> tag in the HTML tab if you are online.
  • Press Ctrl+/ (Cmd+/ on Mac) to comment out the selected lines.

Problems and how to fix them

My JavaScript says an element is null

Check that the id in getElementById matches the HTML exactly, including upper and lower case.

A loop was stopped

Your loop ran more than 2.5 seconds, usually because its condition never becomes false. Fix the condition and run again.

localStorage or cookies give an error

The preview is sandboxed for your safety, so it has no storage of its own. Downloaded files can use storage normally.

The shared link opens an error

The link was probably cut short when it was copied. Ask for it again, or use a downloaded file.

alert() or prompt() do not appear

Some browsers block pop-up dialogs from sandboxed frames. Use console.log() instead.

Questions and answers

Is my code uploaded?

No. It runs in your browser and is saved only in this browser. A share link contains the code itself after the # sign, which browsers do not send to servers.

Is it safe to run code from others?

The preview runs in a sandbox that cannot read this site, your cookies or saved data, and cannot redirect the page. Still, only run code you are willing to have running in a tab.

Can I use libraries like jQuery or React?

Yes, when you are online, by adding a script tag with the library address in the HTML tab.

Why did my loop stop?

Loops that run longer than 2.5 seconds are stopped to keep the page responsive.

Does it work offline?

Yes, once the page has loaded, as long as your code does not load anything from the internet.
