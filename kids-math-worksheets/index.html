What is Kids Math Worksheets?

Kids Math Worksheets makes printable maths worksheets for children aged about 4 to 11, with a separate answer key page. There are eleven kinds: counting pictures, missing numbers, number lines, place value, comparing numbers with <, > and =, column addition and subtraction, fractions with shaded shapes, telling the time on clock faces, counting money, word problems and shapes.

Every sheet has a header with the child's name and the date, comes as an A4 or US Letter PDF, and can also be solved on screen with instant checking and stars.

Each worksheet has a code. The same code with the same settings always makes the same sheet, so you can print it again or share it with another family or class.

Step-by-step tutorial: how to use Kids Math Worksheets

  1. Choose a worksheet

    Tap one of the eleven types, such as Telling the time or Fractions.

  2. Pick the difficulty

    Easy (about age 4–6), Medium (6–8) or Hard (8–11).

  3. Choose how many questions

    Fill one page, or choose a number; more questions add pages.

  4. Set the extras

    For columns choose addition, subtraction and carrying. For money choose the currency symbol and whole numbers or decimals.

  5. Add the header

    Type the child's name and the date, or leave them empty for blank lines. Choose A4 or US Letter.

  6. Check the preview

    Look through the worksheet pages and the answer key.

  7. Download or solve

    Press Download PDF + answer key and print at 100%, or press Solve it here to answer on screen.

Worked example: telling the time

Choose Telling the time, Medium and Fill one page. You get nine clock faces with times like 3:15, 7:30 and 10:45, each with two boxes for the hours and minutes. The answer key on page 2 lists every time with words, for example 3:45 (quarter to 4). Press Solve it here and a child can type 3 and 45 under each clock to earn a star.

Tips and tricks

  • Print at 100% or Actual size so the drawings keep their shape.
  • Write the worksheet code on the sheet's back if you want to print it again later.
  • Start with Easy and move up when a child gets almost everything right.
  • For column sums, choose Without carrying first, then Some of each.
  • In fractions, an answer like 2/4 for a half is accepted on screen as the same fraction.
  • For quick times-table drills use Math Practice.

Problems and how to fix them

The PDF button says it could not make the PDF

The PDF needs two small font files. Open the page once while online, then it also works offline.

Clocks or shapes look stretched on paper

Turn off Fit to page or Scale to fit in the print dialog and print at 100%.

The worksheet changed

A different code or different settings make a different sheet. Type the old code back in with the same settings.

My currency is not in the list

Choose Other and type your symbol, up to four characters, and choose whether it goes before or after the amount.

Questions and answers

Which ages is it for?

Easy suits about ages 4 to 6, Medium about 6 to 8 and Hard about 8 to 11. Every type has all three levels.

Can I print the same worksheet again?

Yes. Each sheet has a worksheet code. The same code with the same settings always makes exactly the same questions.

Is there an answer key?

Yes. The answers are on separate pages at the end of the PDF, so you can print the questions alone.

Which currencies can I use for money sheets?

Pick from many symbols such as $, €, £, ¥, ₹, ₦, ₱ or Rp, or type your own. The coins and notes are simple neutral drawings, not pictures of real money.

Can children do it on a tablet?

Yes. Solve it here shows the questions on screen with big answer boxes, checks each answer and gives a star for each right answer.

Is it free?

Yes. Worksheets are made in your browser with no sign-up, no watermark and nothing uploaded.
