How to use Image Text Editor

  1. Choose a picture and wait a moment while the editor finds the writing.
  2. Click a highlighted line in the picture.
  3. Type the new text. Change the font, size or colour if needed.
  4. Press Save picture, then Download.

Questions and answers

How does it edit text that is part of a picture?

It reads the picture to find each line of writing. When you click a line, it paints over the old words with the colour around them and writes your new text in the same position, size and colour.

Will the new text be in exactly the same font?

Not always. A picture holds only pixels, with no font information, so the editor picks the closest of a few plain fonts by comparing shapes and sizes. You can switch to another font from the list if one fits better.

It did not find the writing in my picture. Why?

Automatic finding works for printed Latin letters and numbers that are reasonably sharp. Handwriting, very small or stylised text, and other scripts such as Urdu or Arabic may be missed. Use Cover old text and Add text to do those by hand.

Why can I see a box where the old text was?

Hiding works best on a plain background. On a photo or a pattern the covered patch is one flat colour, so it shows.

Is my picture uploaded?

No. Finding and editing the text both happen on your own device.
