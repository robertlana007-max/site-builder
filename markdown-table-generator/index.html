What is Markdown Table Generator?

The Markdown Table Generator lets you build a table in a simple grid and get it as Markdown or HTML, ready for GitHub, GitLab, README files, wikis, documentation and forums.

You can paste cells straight from Excel, Google Sheets, LibreOffice or Numbers, import CSV, TSV or semicolon files, or paste an existing Markdown table to edit it.

What you can use it for

README files

Add a table of options, versions or commands to a project README.

Documentation

Turn a spreadsheet of settings or prices into a docs table.

Forums and issues

Post neat tables in GitHub issues, Reddit or Discord-style Markdown.

Editing tables

Paste a hard-to-edit Markdown table, change it in the grid and copy it back.

Quick HTML tables

Get clean HTML table code with alignment for a web page or email.

Step-by-step tutorial: how to use Markdown Table Generator

  1. Fill the grid

    Type in the cells. Press Enter to move down (a new row is added at the end) and Tab to move right.

  2. Or paste from a spreadsheet

    Copy cells in Excel or Google Sheets and paste into any grid cell; they spread out from there.

  3. Or import data

    Open Import, paste CSV, TSV, semicolon data or a Markdown table, or open a file, then press Import.

  4. Shape the table

    Use + Row, + Column, − Row and − Column, or Swap rows and columns.

  5. Set alignment

    Use the menu above each column: left, center or right.

  6. Pick the output

    Choose Markdown or HTML. Line up columns pads the Markdown so it reads well as plain text.

  7. Copy or download

    Press Copy, or Download for a .md or .html file. Open Preview to see the rendered table.

Features

  • Paste from any spreadsheetTab-separated cells from Excel, Sheets, LibreOffice and Numbers fill the grid directly.
  • Smart importDetects tabs, commas, semicolons and Markdown tables, and understands quoted CSV cells with commas and line breaks.
  • Column alignmentLeft, center and right, written as :--, :-: and --: in Markdown and text-align in HTML.
  • Safe outputPipes are escaped as \|, line breaks become <br>, and HTML output escapes < and &.
  • Aligned plain textPretty mode pads cells, counting Chinese, Japanese and Korean characters as double width.
  • Big tablesThousands of rows and up to 100 columns.

From Google Sheets to GitHub

Select a block with Name, Age and City in Google Sheets and copy it. Click the first cell of the grid and paste. Set the Age column to Right. Press Copy and paste into your README: | Name | Age | City | with a --: under Age so the numbers line up on the right.

Tips and tricks

  • Keep First row is the header ticked: Markdown tables always need a header row.
  • Very wide tables are hard to read on phones; consider splitting them.
  • Use the HTML output when you need line breaks or alignment in places that do not support Markdown.
  • Paste a Markdown table into Import to fix its alignment automatically.

Problems and how to fix them

Pasting put everything in one cell

The copied text had no tabs. Paste it into Import instead, where commas and semicolons are detected.

Columns are not lined up on my site

Markdown viewers draw tables themselves; spacing only matters in plain text. Turn off Line up columns for compact output.

Some rows are missing in the editor

The editor shows the first 500 rows. The output still includes every row.

Questions and answers

Can I paste from Excel or Google Sheets?

Yes. Copy the cells and paste them into any cell of the grid; they fill the grid from that cell. You can also paste CSV, semicolon-separated data or an existing Markdown table under Import.

Does it handle pipes and line breaks in cells?

Yes. A | in a cell is written as \| so it does not break the table, and line breaks become <br>.

What does Line up columns do?

It pads cells with spaces so the columns line up in plain text, which is easier to read and edit. Chinese, Japanese and Korean characters count as two columns wide.

Is there a size limit?

You can import up to 100 columns and thousands of rows. The editor shows the first 500 rows, and the output always contains all of them.
