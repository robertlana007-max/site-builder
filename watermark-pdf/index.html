How to use Watermark PDF

  1. Choose a PDF.
  2. Type the watermark text.
  3. Choose the style, strength and color.
  4. Click Add watermark, then Download.

Questions people ask

Can someone remove the watermark?

It becomes part of each page, but a person with PDF editing software could remove it. It discourages casual copying rather than preventing it.

Which characters can I use?

Latin letters, numbers and common symbols. Other scripts are not supported by the built-in font.

Does it hide the text underneath?

No. The watermark is see-through. Use Light if the page must stay easy to read.
