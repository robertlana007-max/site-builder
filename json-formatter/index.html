JSON Formatter

Paste JSON to make it readable, check that it is valid, or minify it. Your data is processed locally and never uploaded.

Runs on your device. Nothing is uploaded.

How to use JSON Formatter

  1. Paste your JSON.
  2. Click Format for readable output or Minify for the smallest output.
  3. If it is invalid, the message shows what went wrong and where.

Questions and answers

Is my JSON sent to a server?

No. Parsing and formatting happen in your browser, so it is safe for API responses and config files.

Why is my JSON invalid?

Common causes are a trailing comma, single quotes instead of double quotes, and keys without quotes.

Does formatting change my data?

Only the whitespace changes. Note that duplicate keys collapse to the last value and very large numbers may lose precision, as with any standard JSON parser.
