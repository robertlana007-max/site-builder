What is IP Subnet Calculator?

The IP Subnet Calculator works out the network address, broadcast address, usable host range, subnet mask and wildcard mask for any IPv4 address and prefix. It also splits a network into smaller subnets and finds the right size for a number of hosts.

For IPv6 it expands and compresses addresses, finds the network and its first and last address, and names the address type. It is useful for network engineers, students preparing for networking exams and anyone setting up routers, firewalls or cloud networks.

All calculations happen in your browser.

What you can use it for

Plan a network

Find how many devices fit in a /24 or /26 and which addresses they get.

Configure a router or firewall

Get the subnet mask and wildcard mask (used in access lists) for a prefix.

Split a network

Divide a range such as 10.0.0.0/16 into equal smaller subnets for offices or cloud subnets.

Size a subnet

Type the number of hosts you need and get the smallest prefix that fits.

Study for exams

Check your own subnetting answers, including binary masks.

Read IPv6 addresses

Expand a shortened IPv6 address or shorten a long one correctly.

Step-by-step tutorial: how to use IP Subnet Calculator

  1. Enter an address

    Type an address with a prefix, such as 192.168.1.10/24, or with a mask, such as 10.0.0.1 255.255.240.0. If you leave out the prefix, choose it from the Subnet mask list.

  2. Read the summary

    The boxes show the network, the number of usable hosts, the mask and the broadcast address.

  3. Check the details

    The table lists the usable host range, total addresses, wildcard mask, class, address type (such as private or public), binary forms with network bits highlighted, hex, integer and the reverse DNS (PTR) name.

  4. Find a size from hosts

    Type a number in Hosts needed. The tool picks the smallest prefix that fits, allowing for the network and broadcast addresses.

  5. Split into subnets

    Choose a New prefix under Split into smaller subnets to list every subnet with its usable range and broadcast. Copy the list as CSV for a spreadsheet.

  6. Use IPv6

    Type an IPv6 address, for example 2001:db8::1/48. Without a prefix, /64 is used. You get the expanded and compressed forms, the network, the first and last address and the number of /64 networks.

Worked example: 172.16.5.130/26

A /26 mask is 255.255.255.192, so each network has 64 addresses. 130 falls in the block 128–191, so the network is 172.16.5.128 and the broadcast is 172.16.5.191. Usable hosts are 172.16.5.129 to 172.16.5.190, which is 62 devices. The wildcard mask is 0.0.0.63 and the address type is private (RFC 1918). Splitting it into /28 gives four subnets of 14 usable hosts each.

Tips and tricks

  • Usable hosts are total addresses minus 2, because the first is the network address and the last is the broadcast address.
  • A wildcard mask is the subnet mask with the bits flipped; Cisco access lists use it.
  • Cloud providers often reserve extra addresses in each subnet (for example five in some services), so plan a little spare room.
  • In IPv6, keep LANs at /64; smaller networks break automatic address setup.

Problems and how to fix them

It says my mask is not valid

A subnet mask must be a run of 1 bits followed by 0 bits, such as 255.255.255.0. A value like 255.0.255.0 is not a mask.

The address is the network address

If you typed the first address of the block, the tool notes that it cannot be given to a device. Pick an address inside the usable range.

Leading zeros are rejected

Numbers such as 010 are read as octal by some systems, so they are refused. Write 10 instead.

The subnet list stops at 1,024

Splitting into very small subnets can create millions of entries. The first 1,024 are shown and the total is given above the list.

Questions and answers

How many hosts does a /24 have?

256 addresses, of which 254 can be used by devices. The first is the network address and the last is the broadcast address.

What is CIDR notation?

The /number after an address is the prefix length: how many bits, from the left, belong to the network. /24 equals the mask 255.255.255.0.

Why does /31 show 2 usable hosts?

RFC 3021 allows both addresses of a /31 to be used on point-to-point links, where no broadcast is needed.

Does it support IPv6?

Yes, for the basics: expand and compress addresses, network range, first and last address, address type and counts.
