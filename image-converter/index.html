How to use Image Converter

  1. Click the box or drop an image onto it.
  2. Choose the format you want.
  3. For JPG or WebP, set the quality.
  4. Click Convert, then Download.

Frequently asked questions

Which format should I choose?

Use JPG for photos, PNG for screenshots, logos and anything with transparency, and WebP when you want the smallest file for a website.

What happens to transparent areas in a JPG?

JPG cannot store transparency, so transparent areas become white.

Is the original image changed?

No. Your original file is left untouched and a new file is created for download.
