    What is Meta Tag Generator?

    The Meta Tag Generator writes the HTML meta tags that control how your web page appears in search results and when its link is shared. You fill in plain fields like title, description and image, and it produces the standard tags, the Open Graph tags used by Facebook, LinkedIn and WhatsApp, and X (Twitter) card tags.

    Live previews show the Google result and the social cards as you type, and a list of checks warns about titles that will be cut off, missing images or links that are not complete. It suits bloggers, small businesses, shop owners, marketers and web developers.

    Everything runs in your browser. The only thing loaded from outside is your own share image, to show it in the preview and measure its size.

    What you can use it for

    New web pages

    Create a complete set of head tags for a new site, landing page or blog post.

    Better search results

    Write a title and description that fit in Google's results without being cut off.

    Attractive social shares

    Make sure links show a large image, title and description on social media and chat apps.

    Fix broken previews

    Find out why a shared link has no image or the wrong text.

    Website builders

    Generate tags to paste into the custom head code field of your site builder or CMS.

    Step-by-step tutorial: how to use Meta Tag Generator

    1. Write the title

      Type the page title. The counter shows characters and pixel width; stay under about 60 characters so Google shows all of it.

    2. Write the description

      Summarise the page in one or two sentences, 70 to 160 characters, as if persuading someone to click.

    3. Add links

      Enter the full page URL starting with https:// and your site name. Paste the full link to a share image of 1200 × 630 pixels and describe the image.

    4. Choose options

      Pick the page type, language and X card style. Search options control indexing; leave both ticked for normal public pages.

    5. Check the previews

      Look at the Google, Facebook/LinkedIn/WhatsApp and X previews and read the Checks list for anything to fix.

    6. Copy the code

      Press Copy HTML and paste the tags inside <head> … </head> of your page, or Download .html for a starter file.

    Worked example: a product page

    A pottery shop types the title "Handmade Ceramic Mugs | Clay & Co" (34 characters), a 115-character description, the URL https://clay.example.com/shop/mugs and a 1200 × 630 image link. All checks turn green. The Google preview shows clay.example.com › shop › mugs above the blue title, and the Facebook card shows the photo, CLAY.EXAMPLE.COM and the title. They press Copy HTML and paste the 24 lines into their shop's head code.

    Tips and tricks

    • Put the most important words at the start of the title; the end may be cut off on phones.
    • Write a different title and description for every page of your site.
    • Use an image with little text and a clear subject; it is shown small in chat apps.
    • Image and page links must be full links starting with https:// for social apps to read them.
    • After publishing, test your link in each platform's sharing debugger to refresh old previews.

    Problems and how to fix them

    The preview image does not show

    Use a full https:// link to an image that is public. Links to private files or pages that need a login cannot be loaded.

    Google shows a different description

    Google sometimes writes its own snippet when it thinks another part of the page answers the search better. A clear, accurate description makes this less likely.

    The canonical tag is missing

    It is only added when the page URL is a full link starting with http:// or https://.

    My site already has some of these tags

    Remove the old tags first so each tag appears only once in the page head.

    Questions and answers

    How long should the title and description be?

    Aim for 30 to 60 characters for the title, since Google cuts titles at about 600 pixels, and 70 to 160 characters for the description. The counters turn green when you are in range.

    What size should the share image be?

    1200 × 630 pixels (a 1.91:1 ratio) works for Facebook, LinkedIn, WhatsApp and X large cards. The tool loads your image and tells you its real size.

    What are Open Graph tags?

    og: tags are read by Facebook, LinkedIn, WhatsApp, Telegram, Slack, Discord and many other apps to build the preview card when someone shares your link.

    Will these tags improve my ranking?

    A good title and description help people choose your result and make shared links more attractive. They do not guarantee a higher ranking, which mainly depends on your content.

    Why do social apps still show my old preview?

    They cache previews. After changing the tags, use the platform's sharing debugger (for example the Facebook Sharing Debugger or LinkedIn Post Inspector) to refresh it.
