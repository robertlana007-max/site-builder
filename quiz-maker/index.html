What is Quiz Maker?

The Quiz Maker lets you write your own quiz with multiple choice, true/false and short answer questions, then use it three ways: take it on screen with instant marking, share it with anyone as a link, or print it as a paper test with a separate answer key.

It is made for teachers preparing a quick check for understanding, students turning their notes into revision questions, parents helping with homework, and anyone running a quiz for a club or a party.

Everything happens in your browser. Saved quizzes stay on your device, and a share link carries the whole quiz inside it, so there is no account, no upload and nothing that expires.

What you can use it for

Classroom checks

Write five questions at the end of a lesson and share the link so students can test themselves on their phones.

Exam revision

Turn your notes into questions with explanations, then retry only the ones you got wrong until you get them all right.

Paper tests

Print a clean test sheet with spaces for name, date and score, plus an answer key on its own page for marking.

Homework practice

Parents can build a short quiz from a school topic and use the timer for a little exam practice.

Fun quizzes

Make a trivia quiz for friends or family and send it in a chat.

Step-by-step tutorial: how to use Quiz Maker

  1. Name your quiz

    Type a title such as "Chapter 3: The water cycle". You can add instructions for the people taking it, for example that some questions have more than one answer.

  2. Add questions

    Click + Multiple choice, + True / false or + Short answer. Type the question in the box. You can change a question's type later with the menu next to its number.

  3. Mark the right answers

    For multiple choice, fill in 2 to 6 options and tick every correct one. For true/false, choose True or False. For short answer, list each accepted answer on its own line, such as "infiltration" and "percolation".

  4. Add explanations

    Use the optional explanation box to say why an answer is right. It is shown after the quiz is submitted, which turns mistakes into learning.

  5. Choose the settings

    Tick Shuffle question order or Shuffle answer options so every attempt is a little different, and set a time limit in minutes if you want one. 0 means no limit.

  6. Try it and save it

    Click Take this quiz to check it works, then Save quiz. Saved quizzes appear under My quizzes, where you can edit, take or delete them.

  7. Share or print

    Copy share link puts a link on your clipboard that opens the quiz ready to take. Print paper test prints the questions with letters A to F for options, and the answer key on a new page if that box is ticked.

  8. Back it up

    Export JSON downloads the quiz as a file. Import JSON loads it again on any device.

Features

  • Three question typesMultiple choice with one or several right answers, true/false, and short answer with as many accepted answers as you like.
  • Instant marking with reviewEach question shows whether you were right, your answer, the correct answer and your explanation.
  • Retry wrong answersAfter a quiz, practise only the questions you missed.
  • Optional timerSet a time limit. When it runs out, the quiz is submitted automatically.

  • Printable test and answer keyPrint a ready-to-use paper version for a classroom.
  • Saved quizzes and JSON filesKeep quizzes in your browser and move them between devices with export and import.

Tips and tricks

  • Keep options similar in length so the right answer does not stand out.
  • For short answers, add common spellings and synonyms as extra accepted answers.
  • Write explanations for every question; they are the most useful part when someone gets it wrong.
  • Use shuffle when several students sit side by side, so their screens differ.
  • Export important quizzes as JSON so you keep a copy if your browser data is cleared.
  • Share links contain the answers, so use them for practice rather than graded exams.

Problems and how to fix them

It says a question has no correct option ticked

Each multiple choice question needs at least one ticked option. Tick the box next to every correct answer.

The share link is very long

Long quizzes make long links, and some chat apps cut them. Share the exported JSON file instead, or split the quiz into two.

The link says it is damaged

Part of the link was probably lost when it was copied. Ask for it again and copy the whole link, including everything after the # sign.

My saved quizzes disappeared

Quizzes are stored in the browser. Clearing site data or using a private window removes them. Keep backups with Export JSON.

A correct short answer was marked wrong

Add that wording as another accepted answer on its own line. Capitals, extra spaces and a final full stop are already ignored.

Questions and answers

Do the people I share with need an account?

No. They just open the link. The quiz is stored inside the link itself, so it works without any sign-up and nothing is kept on a server.

Can students see the answers in the link?

The answers have to be inside the link so the quiz can be marked in the browser. They are compressed, not hidden, so a determined person could decode them. Use it for practice and revision, not for high-stakes exams.

Can a question have more than one correct answer?

Yes. Tick every correct option. The person taking the quiz is told how many to choose, and the question only counts as right when they pick exactly those options.

How are short answers marked?

The answer is compared with each accepted answer you list. Capital letters, extra spaces and a final full stop are ignored, and numbers like 3 and 3.0 count as the same.

Where are my quizzes saved?

In this browser only. Use Export JSON to keep a backup or to move a quiz to another device, then Import JSON there.

Is there a limit on questions?

A quiz can have up to 200 questions. Very long quizzes make long share links, so for big quizzes share the exported file instead.
