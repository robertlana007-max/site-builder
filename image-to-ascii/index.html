What is Image to ASCII Art?
Image to ASCII Art turns any picture into text art made of letters, numbers and symbols. Dark parts of the picture become dense characters such as @ and #, light parts become dots and spaces, so the shape of the picture appears in plain text.
Choose the width in characters, the character set, brightness and contrast, and whether to invert the shading for dark backgrounds. You can also keep the original colours as an HTML page or PNG picture.
The conversion happens in your browser. Your picture is not uploaded.


What you can use it for
Code comments and READMEs
Add a text logo to the top of a script or project page.
Chat messages
Share a picture as text in a code block.
Terminal banners
Create a login message or command-line tool banner with inverted art.
Retro art and prints
Make coloured ASCII posters and download them as PNG.
Teaching
Show how brightness maps to characters in computing or art lessons.


Step-by-step tutorial: how to use Image to ASCII Art
  1. Add a picture
    Click, drop or paste a picture, or press "Try with a sample picture". Simple pictures with strong contrast give the clearest results.
  2. Set the width
    Drag the Width slider. 60 to 100 characters suit chats and code; 150 to 300 shows fine detail for PNG and HTML.
  3. Choose characters
    Standard is a good start. Detailed uses 70 shades, Blocks gives a solid look, Binary uses 0 and 1, and "My own characters" uses any characters you type from light to dark.
  4. Adjust the look
    Use Brightness and Contrast to bring out detail. Tick Invert for light text on a dark background, and Dark preview to see it that way.
  5. Choose the output
    Plain text is for copying. Colour (HTML) keeps the colours of the picture.
  6. Copy or download
    Press Copy text, or download TXT, PNG or (for colour) HTML.


Features
  • Adjustable widthFrom 20 to 300 characters, with the height worked out for you.
  • Six character setsIncluding blocks, binary and your own characters.
  • Brightness, contrast and invertFine control over the shading.
  • Colour outputColoured HTML page and coloured PNG.
  • Copy and downloadText, PNG and HTML downloads, and one-tap copy.
  • Handles transparencySee-through areas become empty space.


Worked example: a logo for a README
Maya wants her project logo at the top of a README file. She drops the logo PNG in, sets the width to 70 characters and picks the Standard character set. The logo is dark on a transparent background, so the shape shows clearly. She raises Contrast to 30 to sharpen the edges, presses Copy text and pastes it inside a code block in her README.


Tips and tricks
  • Always paste ASCII art into a monospaced font, such as a code block.
  • Pictures with a plain background and strong outlines convert best.
  • Raise the contrast if the result looks grey and flat.
  • For terminals with dark backgrounds, tick Invert.
  • Use My own characters to write in the shape of a picture with only a few symbols, such as " .:*".


Problems and how to fix them
The art looks stretched or squashed when pasted
The app is not using a monospaced font. Paste it into a code block or text editor with a monospace font.
The result is mostly one character
The picture is very dark or very light. Adjust Brightness and Contrast.
The lines wrap in my chat
Lower the width so each line fits the chat window.



Questions and answers


Why does my ASCII art look squashed when I paste it?
ASCII art needs a monospaced font, where every character is the same width. Paste it into a code block, a text editor or a chat that supports monospace.
What width should I use?
About 60 to 80 characters fits chats and code comments. 120 to 200 shows much more detail for PNG or HTML.
What does Invert do?
Normally dark parts of the picture use dense characters, which suits dark text on a light page. Invert swaps this for light text on a dark background, such as a terminal.
Is my picture uploaded?
No. The conversion happens entirely in your browser.
Can I get colours?
Yes. Choose Output: Colour (HTML). Each character keeps the colour of that part of the picture, and you can download it as an HTML page or a PNG.
