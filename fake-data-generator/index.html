What is Fake Data Generator?

The Fake Data Generator creates realistic test data: names, emails, phone numbers, addresses, companies, dates, UUIDs, numbers and more, for 16 countries and languages.

All of it is made up from built-in word lists. Emails use the reserved example.com, example.org and example.net domains, and US and UK phone numbers use ranges set aside for fiction. Data is generated in your browser and can be downloaded as CSV, JSON, JSON Lines or SQL INSERT statements.

What you can use it for

Testing apps

Fill forms, lists and databases with realistic data while developing.

Demos and screenshots

Show a product with believable data instead of real customers.

Spreadsheet practice

Create sample tables for teaching Excel, SQL or data analysis.

Internationalization

Test how your app handles accents, Cyrillic, Arabic, Chinese and Japanese names.

Load tests

Make thousands of rows to import in one go.

Step-by-step tutorial: how to use Fake Data Generator

  1. Pick a country

    Choose a country or language for names, cities, address and phone formats, or Mixed for all. The list starts with your browser language when it is one of them.

  2. Set up columns

    Each row is a column: choose the type and edit the column name. Add up to 40 columns or remove ones you do not need.

  3. Choose the size and format

    Set Rows (up to 10,000) and pick CSV, JSON, JSON Lines or SQL INSERT. For SQL, set the table name.

  4. Optional seed

    Enter a seed like 42 to get exactly the same data every time.

  5. Generate

    Press Generate and check the preview of the first rows.

  6. Copy or download

    Press Copy or Download. CSV files open directly in Excel with accents intact.

Features

  • 16 localesUnited States, United Kingdom, India, Spain, Mexico, France, Germany, Italy, Brazil, Netherlands, Türkiye, Indonesia, Russia, Egypt, Japan and China.
  • Consistent rowsEach row is one made-up person, so the name, email and username match, and age matches the birth date.
  • 32 data typesFrom UUIDs and passwords to IPv6 documentation addresses, hex colours and coordinates.
  • Four formatsCSV with BOM for Excel, pretty JSON, JSON Lines and batched SQL INSERT statements.
  • RepeatableA seed gives the same data every time.
  • Safe by designReserved email domains and documentation IP ranges, nothing taken from real people.

Test users for a signup page

Choose English (United Kingdom), keep the default columns, set Rows to 500 and Format to SQL INSERT with table users. Press Generate and download fake-data.sql: 500 users such as Oscar Moore, oscarm29@example.net, phone 07700 900388, ready to import into your test database.

Tips and tricks

  • Use Mixed to test how your app handles many scripts at once.
  • Keep a seed in your test scripts so everyone gets the same data.
  • For very large data sets, generate several batches with different seeds.
  • Rename columns to match your database before generating SQL.

Problems and how to fix them

Two columns are both called…

Every column needs its own name. Change one of them.

Excel shows strange characters

Open the CSV by double-clicking it, or use Data > From Text/CSV and choose UTF-8.

Phone numbers look real

Outside the US and UK there are no reserved fictional ranges, so numbers are random. Never call or message them.

Questions and answers

Are these real people?

No. Names, addresses and companies are random combinations of common words, and emails use example.com, example.org and example.net, which are reserved and never belong to anyone.

Are the phone numbers real?

They follow each country's format. United States numbers use the fictional 555-01xx range and United Kingdom numbers the Ofcom drama range. Elsewhere they are random and could match a real number, so never call or text them.

What is the seed for?

With the same seed and settings you get exactly the same data again, which helps with repeatable tests.

How many rows can I make?

Up to 10,000 per batch, made in your browser in about a second.
