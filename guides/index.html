You can also add new text anywhere and hide any area by hand.8 steps · 6 tips · 5 fixes

Developer tools

Format and check JSON, encode and decode Base64 and URLs, make hashes, test regular expressions and convert colours.

How to use JSON FormatterThe JSON Formatter takes JSON text and makes it easy to read, checks that it is valid, or squeezes it into one compact line. Base64 writes any data using only letters, digits, plus (+), slash (/) and the equals sign (=), so it can travel safely through systems that only accept plain text.6 steps · 6 tips · 4 fixesHow to use URL Encoder / DecoderThe URL Encoder / Decoder makes text safe to use inside a web address, and turns encoded addresses full of % signs back into readable text. For example, a space becomes %20 and an ampersand becomes %26.6 steps · 5 tips · 5 fixesHow to use Hash GeneratorThe Hash Generator calculates five hashes of any text or file at the same time: MD5, SHA-1, SHA-256, SHA-384 and SHA-512. A hash is a fixed-length string of letters and numbers that works like a fingerprint for the data. The same text or file always gives the same hash.5 steps · 5 tips · 4 fixesHow to use Color ConverterThe Color Converter changes a color between three common codes: HEX, RGB and HSL. You can pick a color with the color picker or type any of the three formats, and you see all three codes plus a large preview at once.6 steps · 5 tips · 4 fixesHow to use Text to BinaryThe Text to Binary tool turns normal text into binary code, the 0s and 1s that a computer really stores, and turns binary code back into text.
