    What is Chmod Calculator?

    The Chmod Calculator converts Linux and macOS file permissions between checkboxes, octal numbers such as 755 and symbolic text such as rwxr-xr-x. It explains in plain words who can read, change and run the file, and gives the ready chmod command.

    It helps developers, website owners, students and server admins who need the right permissions for scripts, web files, SSH keys or shared folders, including the special setuid, setgid and sticky bits.

    It runs in your browser and does not touch any files.

    What you can use it for

    Web hosting

    Find the usual 644 for files and 755 for folders on a web server.

    Scripts

    Make a script executable for its owner with 755 or 700.

    SSH keys

    Set private keys to 600 or 400 so SSH accepts them.

    Shared folders

    Use setgid (2775) so new files keep the group, or the sticky bit (1777) like /tmp.

    Read ls -l output

    Paste a permission string like -rwsr-xr-x to see what it means and its number.

    Step-by-step tutorial: how to use Chmod Calculator

    1. Start with what you have

      Type an octal number in Octal, a string like rwxr-xr-x in Symbolic, or tick the boxes. All three stay in sync.

    2. Use the checkbox grid

      Rows are Owner, Group and Others. Columns are Read (4), Write (2) and Execute (1). The Value column adds them up for each row.

    3. Add special bits

      Tick setuid, setgid or sticky if needed. They add a fourth digit in front, such as 4755, and change x to s or t in the symbolic form.

    4. Choose file or folder

      Pick File or Folder. The explanation changes, because execute on a folder means you can open it.

    5. Copy the command

      Copy the numeric command (chmod 755 file) or the symbolic one (chmod u=rwx,g=rx,o=rx file) and replace file with your file name.

    6. Apply a change

      Type an expression such as g+w,o-rwx and click Apply to see what it would do to the current permissions.

    Features

    • Three-way conversionCheckboxes, octal and symbolic update each other instantly.
    • Special bitssetuid, setgid and sticky, shown as s, S, t and T exactly like ls -l.
    • Plain explanationsWho can do what, with a warning when everyone can write.
    • Ready commandsNumeric and symbolic chmod commands to copy.
    • Expression testerTry u+x, go-w, a=rX and other chmod expressions before running them.
    • Common presets644, 755, 600, 700, 664, 775, 444, 400, 777, 1777, 2775 and 4755.

    Worked example: from 644 to a group-writable script

    Start with 644: owner rw- (4+2 = 6), group r-- (4) and others r-- (4), so -rw-r--r--. Type u+x,g+w,o-r and click Apply. The owner gains execute (6+1 = 7), the group gains write (4+2 = 6) and others lose read (4−4 = 0). The result is 760, shown as -rwxrw----, and the command is chmod 760 file.

    Tips and tricks

    • Folders need execute (x) to be opened, so folders are usually 755 while files are 644.
    • Avoid 777 on servers: anyone with access to the machine can change the file.
    • A capital S or T means the special bit is set but execute is not, which is usually a mistake.
    • Use chmod -R carefully on folders: it applies the same numbers to files and folders. a+rX gives execute only to folders and already-executable files.

    Problems and how to fix them

    SSH says my key permissions are too open

    Set the private key to 600 (or 400) so only you can read it.

    The web server shows 403 Forbidden

    The web server user usually needs read on files (644) and read plus execute on every folder in the path (755).

    My script will not run

    It needs execute permission for you, for example 755 or 700, and a correct first line (#!) naming the interpreter.

    Octal is not accepted

    Use 3 or 4 digits, each from 0 to 7, such as 640 or 2775.

    Questions and answers

    What does 755 mean?

    The owner can read, write and execute (7 = 4+2+1); the group and others can read and execute (5 = 4+1).

    What is the difference between 644 and 755?

    755 adds execute for everyone. Use 644 for normal files and 755 for folders and programs.

    What are setuid, setgid and sticky?

    setuid and setgid make a program run with the file owner's or group's rights; setgid on a folder makes new files inherit its group; sticky on a folder lets only owners delete their own files.

    Does this change my files?

    No. It only calculates. Run the copied command in your terminal to change a file.
