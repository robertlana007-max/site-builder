What is Secret Note?

Secret Note locks a private message with a password, so only someone who knows the password can read it. You can share the locked note as a link, as a block of text, or as a QR code.

The note is locked on your device with AES-256-GCM encryption, using a key made from your password with PBKDF2-SHA256 and 600,000 rounds. The locked note in a link sits after the # sign, a part of the address that browsers never send to any server, so the note travels straight from you to the other person.

Nobody can recover a lost password, not even us, because we never see the note or the password.

What you can use it for

Share a Wi-Fi or door code

Send a code to a guest without it sitting in plain text in a chat history.

Send a password to a colleague

Share a login safely: send the link by email or chat, and say the password on a call.

Keep a private note on a public computer

Lock a note, copy the text block somewhere, and only you can open it later.

Hand out a code on paper

Print the QR code on a card; people scan it and type the password you tell them.

Send account details to family

Share bank or insurance numbers in a way that is useless to anyone who sees the message by accident.

Step-by-step tutorial: how to use Secret Note

  1. Write your note

    Type or paste the message into "Your secret note". It can be up to 20,000 characters, in any language, with emoji.

  2. Choose a password

    Type a password and type it again in the second box. The bar under it shows how strong it is. Four or more random words, like a short odd sentence, make a strong password that is easy to say out loud.

  3. Lock the note

    Press "Lock note". It takes about a second, because the password is stretched 600,000 times to make guessing slow.

  4. Share the link, text or QR code

    Copy the link, copy or download the text block, or download the QR code. Every lock gives a different result, even for the same note and password.

  5. Send the password a different way

    Tell the other person the password on a call, in person, or in a different app. Do not put it in the same message as the link.

  6. Open a note

    The other person opens the link: the page shows only a password box. They type the password and press "Open note". If they got a text block, they choose "Open a note", paste it and type the password.

  7. Clean up

    After reading, press "Hide note". If the note came in a link, "Remove the link from this tab" takes it out of the address bar.

Features

  • Strong, standard encryptionAES-256-GCM with a PBKDF2-SHA256 key (600,000 rounds, random 16-byte salt and 12-byte IV), using the browser's built-in Web Crypto.
  • Nothing is uploadedLocking and opening happen in your browser. The note in a link sits after the #, which is never sent to a server.
  • Three ways to shareA link, a text block that survives email and chat, and a QR code to print or show on screen.
  • Tamper checkAny change to the locked note, even one letter, makes opening fail instead of showing wrong text.
  • Password strength hintA live meter warns about common and short passwords.
  • Clear warningsIt warns when a link is very long, and when a note is too long for a QR code.
  • Versioned formatEvery locked note starts with v1., so it can still be opened by future versions of the tool.

Worked example: sending a door code to a guest

Your guest arrives on Saturday and needs the key-box code 4711. You type "Key box by the door: 4711" as the note and choose the password "purple lemon garden". You press Lock note and copy the link into a message to your guest. Then you call them and say the three words. On Saturday they tap the link, type purple lemon garden and see the code. Anyone who reads the message without the password sees only a long jumble of letters.

Tips and tricks

  • Use four or more random words as the password: it is strong and easy to say on the phone.
  • Never send the password in the same message as the link.
  • Passwords are case-sensitive: "Lemon" and "lemon" are different.
  • If a chat app breaks a long link, send the text block or the .txt file instead.
  • Show the QR code on your screen for someone in the same room to scan.

Problems and how to fix them

"Wrong password or damaged data"

The password is wrong (check capital letters and spaces), or part of the link or text was lost when copying. Ask for the link again and copy all of it.

"This does not look like a locked note"

Paste the whole link, or the whole text block from -----BEGIN SECRET NOTE----- to -----END SECRET NOTE-----.

No QR code is shown

The note is too long to fit in a QR code. Shorten it, or share the link or text instead.

I forgot the password

It cannot be recovered by anyone. Ask the sender to lock the note again with a new password.

Questions and answers

Can you read my note?

No. The note is locked and opened in your browser. In a link it sits after the #, a part of the address that browsers never send to a server, so it never reaches us.

What encryption does it use?

AES-256-GCM, with a key made from your password by PBKDF2-SHA256 with 600,000 rounds, a random 16-byte salt and a random 12-byte IV, all through the browser's built-in Web Crypto.

I forgot the password. Can you recover the note?

No. Nobody can. Without the password the note cannot be opened, which is what keeps it safe. Ask the sender to lock it again.

What does "Wrong password or damaged data" mean?

Either the password is wrong (it is case-sensitive), or part of the link or text was lost when copying. The lock includes a tamper check, so a changed note will not open with wrong text.

How long can a note be?

Up to 20,000 characters. Long notes make long links, and above about 2,000 characters the QR code no longer fits; share the link or text then.

Does the link expire?

No. The locked note is inside the link itself, so it works as long as you keep the link and the password.
