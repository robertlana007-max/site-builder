What is Barcode Generator?

Barcode Generator creates scannable barcodes in the most common 1D formats: EAN-13, EAN-8, UPC-A, Code 128, Code 39, ITF-14, MSI Plessey and Pharmacode.

Each format is checked as you type, with clear messages if something is wrong. Check digits for EAN, UPC and ITF-14 are calculated or verified for you, and EAN and UPC barcodes are read back from the finished image and decoded to confirm the bars are correct. Download a PNG at up to 4× resolution, a sharp SVG, or create a whole batch as a ZIP.

Barcodes are drawn in your browser using the open-source JsBarcode library; nothing is uploaded.

What you can use it for

Product labels

Print EAN-13 or UPC-A barcodes for products whose numbers you have from GS1.

Inventory and asset tags

Label stock, equipment or files with Code 128 codes that hold letters and numbers.

Shipping cartons

Make ITF-14 barcodes for outer cases and boxes.

Shelf and library labels

Use Code 39 or MSI codes required by older scanners and systems.

Bulk label printing

Paste a list of codes and get a ZIP of images ready for a label template.

Step-by-step tutorial: how to use Barcode Generator

  1. Pick the barcode type

    Choose from "Barcode type". The hint under it explains what that format accepts.

  2. Type the value

    For EAN-13 type 12 digits and the check digit is added; type 13 to have it checked. Code 128 accepts any plain text.

  3. Check the result

    The barcode appears straight away. For EAN and UPC a green line confirms the bars were decoded back to your number. Read any message in red to fix a mistake.

  4. Style it

    Set the bar width, height, quiet zone, text size and colours. Untick "Show the value under the bars" for bars only, or type custom text.

  5. Download

    Click "Download PNG" (choose 1×, 2× or 4× resolution) or "Download SVG" for print and design software.

  6. Make a batch (optional)

    Paste one value per line under "Batch", choose PNG or SVG, and click "Create ZIP". Lines that are not valid are skipped and listed.

Worked example: an EAN-13 label

Maria's company was given the GS1 number 590123412345 for a new product. She chooses EAN-13 and types those 12 digits. The tool adds the check digit 7, shows 5901234123457 under the bars and confirms the image decodes to 5901234123457. She sets Bar width to 3 px and PNG resolution to 4× (print), and downloads barcode-ean13-5901234123457.png, plus an SVG for the packaging designer.

Tips and tricks

  • Keep dark bars on a light background. Red, light grey or inverted barcodes often fail to scan.
  • Leave the quiet zone (margin) on: scanners need blank space either side of the bars.
  • For print, use SVG or PNG at 4×, and do not stretch the image unevenly.
  • EAN and UPC numbers for retail must come from GS1; making up a number can clash with someone else's product.
  • Code 128 is the most compact choice for text and mixed letters and numbers.

Problems and how to fix them

It says the last digit should be different

The check digit you typed does not match the rest of the number. Check for a typing mistake, or type the number without its last digit and the right one is added.

My text is not accepted in Code 39

Code 39 only has capital letters, digits, space and - . $ / + %. Use Code 128 for other characters.

A scanner will not read my printed barcode

Print larger, keep the margins, use black on white, and make sure the printer is not blurring thin bars. Choose a bar width of 2 px or more.

Code 128 rejects an accented letter or emoji

Code 128 holds plain keyboard characters only. Replace accented letters, for example é with e.

Questions and answers

Which barcode type should I use?

EAN-13 (or UPC-A in the US and Canada) for products sold in shops, ITF-14 for shipping cartons, and Code 128 for labels, inventory and anything with letters.

Do I need to type the check digit?

No. Type 12 digits for EAN-13 (11 for UPC-A, 7 for EAN-8, 13 for ITF-14) and the check digit is added. If you type it, the tool tells you whether it is right.

Can I use these barcodes on products in shops?

The barcodes are standard and scannable, but retail product numbers must be registered with GS1. Do not invent EAN or UPC numbers for products you sell.

PNG or SVG?

SVG stays sharp at any size and is best for print and design software. PNG suits documents and websites; choose 4× resolution for print.

How do I make many barcodes at once?

Paste one value per line in the Batch box and click Create ZIP. Invalid lines are skipped and listed.

Is my data uploaded?

No. Barcodes are drawn in your browser and nothing leaves your device.
