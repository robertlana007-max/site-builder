Frequently asked questions

How is text turned into binary?

Each character is stored as one or more bytes using UTF-8, and each byte is written as eight binary digits.

Why do some characters use more than 8 digits?

English letters take one byte. Accented letters, other scripts and emoji take two to four bytes each.

Do spaces between groups matter when decoding?

No. Spaces and line breaks are ignored, as long as the total number of digits is a multiple of 8.
