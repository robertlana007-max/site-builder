What is Roman Numeral Converter?

The Roman Numeral Converter changes normal numbers into Roman numerals and Roman numerals back into numbers. It has two boxes; type in either one and the other updates right away. It supports whole numbers from 1 to 3999.

It is useful for reading dates on buildings and film credits, writing years for tattoos, invitations or clock faces, checking school homework, and understanding chapter or event numbers like Super Bowl LX. It also checks that a numeral is written correctly.

The conversion runs in your browser as you type.

Validate a numeral

Step-by-step tutorial: how to use Roman Numeral Converter

  1. Type a number

    Enter a whole number from 1 to 3999 in "Number (1 to 3999)". The Roman numeral appears in the other box at once.

  2. Or type a Roman numeral

    Enter letters in "Roman numeral", using I, V, X, L, C, D and M. Lowercase is fine; it is changed to capitals as you type. The number appears in the first box.

  3. Read the message line

    Below the boxes, a short line gives help. If the input is not valid, it explains why, for example "Roman numerals cover whole numbers from 1 to 3999."

  4. Fix an invalid entry

    If a numeral is not valid, the number box is cleared and the message shows the text you typed, such as "IIII" is not a valid Roman numeral. Correct the letters and the number appears again.

  5. Clear to start again

    Empty either box and the other one clears too.

Features

  • Number to numeralThe tool takes the largest value it can from this list each time: M 1000, CM 900, D 500, CD 400, C 100, XC 90, L 50, XL 40, X 10, IX 9, V 5, IV 4, I 1.
  • Numeral to numberIt reads the letters from left to right using the same list and adds up the values.
  • Strict checkingA numeral is accepted only if converting it back gives exactly the same letters, so forms like IIII, VX or IC are rejected.
  • Two-way live updateType in either box; there is no convert button.
  • Clear limitsOnly whole numbers from 1 to 3999 are allowed, with a message if you go outside the range.

Worked example: 2026 and MCMXCIV

Type 2026 in the number box. The tool takes M (1000) twice, then X (10) twice, then V (5) and I (1), so the numeral is MMXXVI. Now type MCMXCIV in the Roman numeral box. It reads M = 1000, CM = 900, XC = 90 and IV = 4, and shows 1994. If you type IIII, the message says "IIII" is not a valid Roman numeral, because the standard form of 4 is IV.

Tips and tricks

  • Remember the subtractive pairs: IV 4, IX 9, XL 40, XC 90, CD 400, CM 900.
  • Clock faces sometimes show IIII, but this tool follows the standard form IV.
  • Spaces at the start or end of a numeral are ignored.
  • For years above 3999, standard Roman numerals need special overline marks, which this tool does not support.
  • Type the year first and copy the numeral from the second box.

Problems and how to fix them

It says the numeral is not valid

Use only I, V, X, L, C, D and M in standard order. Forms like IIII, VV or IC are not accepted.

It says numerals cover 1 to 3999

You typed 0, a negative number, a decimal or a number above 3999. Enter a whole number in range.

The other box is empty

When the input is not valid, the other box is cleared. Fix the input and it fills again.

My lowercase letters changed

Lowercase letters are changed to capitals as you type. This is normal and does not change the result.

Questions and answers

Why does it stop at 3999?

Standard Roman numerals have no symbol above M (1000), and no symbol repeats more than three times, so 3999 (MMMCMXCIX) is the largest.

How do Roman numerals work?

Symbols are added together, largest first. A smaller symbol before a larger one is subtracted, so IV is 4 and IX is 9.

Is there a Roman numeral for zero?

No. The system has no zero.
