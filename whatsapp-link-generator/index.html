What is WhatsApp Link Generator?

The WhatsApp Link Generator makes a click-to-chat link in the public wa.me format. When someone opens the link, a chat with your number opens, optionally with a message already typed for them.

Pick the country, type the number as you normally dial it, and the tool removes spaces, dashes, the + sign and the domestic leading 0 for you. It also makes a QR code of the link that you can download and print.

A built-in text formatter helps you write messages with bold, italic, strikethrough, monospace, lists and quotes, with a live preview. It is an independent tool, not made by WhatsApp or Meta, and runs entirely in your browser.

Business contact buttons

Put a "Chat with us" link on your website, Instagram bio or Facebook page.

Printed QR codes

Print the QR code on shop counters, menus, flyers, business cards or packaging.

Ready-made order messages

Pre-fill a message like "Hi, I want to order…" so customers only press send.

Customer support

Formatted announcements

Write a styled message with bold headings and lists, then copy it into a chat or broadcast.

Step-by-step tutorial: how to use WhatsApp Link Generator

  1. Pick the country

    Choose the country in "Country code". If your number already starts with + and the country code, you can choose "Number already has the code".

  2. Type the phone number

    Type it as you would dial it in that country, for example 0300 1234567 in Pakistan or 07911 123456 in the UK. The line below shows the international number used, like +923001234567.

  3. Add a message (optional)

    Type the text you want to appear ready to send. It is URL-encoded for you, so spaces, emoji, & and new lines work.

  4. Copy or test the link

    The link appears in the grey box. Click "Copy link", or "Open to test" to check it opens the right chat.

  5. Download the QR code

    Scan the QR code with your phone to test it, then click "Download QR (PNG)" to save it for printing.

  6. Format a message

    In the Text formatter, type your text, select a word or line and tap B, I, S, Mono, a list or quote button. The green preview shows how it will look. Click "Use as the link message" to put it into the link.

Worked example: a bakery order link

Your bakery's number is 0321 7654321 in Pakistan. You choose Pakistan (+92), type 0321 7654321, and the tool shows "Number used: +923217654321". You type the message "Hi! I would like to order a cake for". The link becomes https://wa.me/923217654321?text=Hi!%20I%20would%20like%20to%20order%20a%20cake%20for. You click "Open to test", then download the QR code and print it on your boxes.

Tips and tricks

  • Always test the link on your phone before you print it or share it widely.
  • Use a number that has WhatsApp installed. The link cannot create an account.
  • Keep the prefilled message short and end it so the customer can finish the sentence.
  • For Italy, landline numbers keep their leading 0 and the tool keeps it for you.
  • Print the QR code at least 2 to 3 cm wide and keep the white border around it.
  • WhatsApp Business users can put the link in their profile, catalogue and auto-replies.

Problems and how to fix them

"A number starting with 0 is a local number"

No country is chosen, so the tool cannot tell which country the number is in. Pick the country, or type + and the country code.

"That number looks too short"

Type the full number including the area or mobile code, not just the last digits.

The link opens WhatsApp but says the number is not on WhatsApp

Check the country and number shown under the box. The number may be wrong or not registered on WhatsApp.

The QR code says the message is too long

A QR code can hold a limited amount of text. Shorten the prefilled message.

Formatting does not show in WhatsApp

Markers must touch the text: *bold* works, * bold * does not. Select the words without spaces before tapping a style.

Questions and answers

What is a wa.me link?

It is WhatsApp's public click-to-chat address. Opening https://wa.me/ followed by a number in international format starts a chat with that number.

Should I include the 0 or the + sign?

No. Links use the country code and number only, with no +, spaces or domestic 0. The tool removes them for you, so you can type the number as you normally dial it.

Can I make a link without a phone number?

Yes. Leave the number empty and type a message. The link lets the person pick who to send that message to.

How do I write bold or italic text in WhatsApp?

Put *stars* around bold text, _underscores_ for italic, ~tildes~ for strikethrough and three backticks for monospace. The formatter does this for you with a live preview.

Is this an official WhatsApp tool?

No. It is an independent tool that uses the public link format. It is not made by or affiliated with WhatsApp or Meta.
