What is Color Palette Generator?

The Color Palette Generator makes sets of colours that work together. Pick a rule, such as random, analogous, complementary, split complementary, triadic, square, monochrome, pastel or earthy, choose 3 to 8 colours and press Generate or the space bar.

Lock any colour to keep it while the others change, or pick a colour yourself with the pencil. Each swatch shows its HEX, RGB and HSL values, and tapping the code copies it. Copy the whole palette as CSS variables or a HEX list, download it as a picture, and save favourites on this device.

The Gradient tab builds linear, radial and conic CSS gradients with up to six colour stops. Start from a preset, a random gradient or your palette, then copy the CSS or save a 1920 × 1080 picture.

Step-by-step tutorial: how to use Color Palette Generator

  1. Choose a colour rule

    Pick a rule in "Colour rule" and how many colours you want.

  2. Start from a colour (optional)

    Type a HEX code such as #3b82f6 to build the palette around it.

  3. Generate

    Press Generate or the space bar to get new palettes.

  4. Lock and adjust

    Tap the lock on colours you like. Use the pencil to pick an exact colour.

  5. Copy or save

    Tap a code to copy it, or use Copy CSS, Copy HEX list, Download PNG or Save palette.

  6. Make a gradient

    Press "Make a gradient" or open the Gradient tab. Change the type, angle and stops, then copy the CSS.

Worked example: a palette around a brand colour

A café owner types her logo colour #b45309 in "Start from colour", chooses Analogous and 5 colours, and presses Generate a few times. She locks a warm cream and a dark brown, generates again for the other two, then presses Copy CSS and sends the variables to her web designer.

Tips and tricks

  • Use one strong colour for buttons and links and calmer ones for backgrounds.
  • Check text contrast: dark text on light colours and white text on dark ones.
  • Monochrome palettes are an easy way to look clean and professional.
  • Save palettes you like so you can compare them later.
  • In the Gradient tab, colours that sit close on the colour wheel blend most smoothly.

Problems and how to fix them

The space bar does nothing

Click on an empty part of the page first; it is ignored while you are typing in a box.

My colour code is not accepted

Use a HEX code with 3 or 6 digits, like #f80 or #ff8800.

Conic gradient will not save as a picture

Some older browsers cannot draw conic gradients. Choose Linear or Radial, or update your browser.

Questions and answers

What do the colour rules mean?

Complementary uses opposite colours on the colour wheel; analogous uses neighbours; triadic and square use three or four evenly spaced hues; monochrome uses shades of one hue.

How do I keep a colour I like?

Tap the lock on it. Locked colours stay when you generate again.

Can I start from my brand colour?

Yes. Type its HEX code in "Start from colour" and the palette is built around it.

Can I use the colours in my website?

Yes. Copy CSS gives you ready-made CSS variables, and the Gradient tab gives a background line you can paste in.

Where are saved palettes kept?
