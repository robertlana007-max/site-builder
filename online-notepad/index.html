What is GetToolNest Notepad?

GetToolNest Notepad is a full text and code editor that opens in a browser tab. It looks and works like a desktop editor: a title bar, a menu bar with File, Edit, Search, View, Language, Lines and Tools, a toolbar, tabs for many files, line numbers, a status bar and keyboard shortcuts. You can write plain notes or code with colours for more than 30 languages.

It is made for anyone who needs more than a simple text box: students taking notes, writers drafting long texts, office workers cleaning lists and data, and developers who need to view or fix a file quickly on a computer where they cannot install software. The Lines and Tools menus also do jobs that normally need separate tools, such as sorting, removing duplicates, formatting JSON or encoding Base64.

Files you open are read by your browser and your tabs are saved in this browser’s own storage, so nothing goes to a server.

What you can use it for

Quick notes that stay put

Type notes, to-do lists or drafts. They are saved automatically and are still there when you come back on the same browser.

View and edit code files

Open .js, .py, .html, .json, .sql and many other files to read or fix them with syntax colours, bracket matching and code folding.

Clean and sort lists

Sort lines, remove duplicates or empty lines, trim spaces, number lines or split a comma list into lines with the Lines and Edit menus.

Search and replace across a document

Replace a word everywhere, or use regular expressions to change patterns such as dates or phone numbers.

Work with data formats

Format or minify JSON, and encode or decode Base64 and URL text from the Tools menu.

Pick lines out of a log

Bookmark every line that contains a word such as ERROR, then copy only those lines or delete all the others.

Step-by-step tutorial: how to use GetToolNest Notepad

  1. Start writing or open files

    Click in the editor and type. Press Alt+N or click the + tab for a new tab. To open files, use File → "Open files…" (Ctrl+O), the folder button, or drag files from your computer onto the editor. Each file opens in its own tab and its language is chosen from the file extension.

  2. Work with tabs

    Click a tab to switch to it, or press Alt+PageDown and Alt+PageUp to move between tabs. A tab with unsaved changes is marked, and the title bar shows a * before its name. Double-click a tab, or use File → "Rename tab…", to rename it. Close tabs with the × on the tab, Alt+W, or File → "Close other tabs" and "Close all tabs"; you are asked before unsaved text is lost.

  3. Save your work

    Ctrl+S or File → "Save (download)" downloads the current tab as a file. "Save as…" lets you type a new file name first; the extension also sets the language. "Save all as ZIP" downloads every tab in one notepad-tabs.zip file. The line ending used is the one picked in the status bar: Unix (LF), Windows (CRLF) or Old Mac (CR).

  4. Edit faster with the Edit menu

    Ctrl+D duplicates the line, Ctrl+L deletes it, Alt+↑ and Alt+↓ move the line or selected lines up and down, Ctrl+J joins the selected lines into one, and Ctrl+/ comments lines in or out for the current language. Tab and Shift+Tab indent and outdent. The same menu changes case (Ctrl+Shift+U for UPPERCASE, Ctrl+U for lowercase, plus Title Case, Sentence case and iNVERT cASE), trims spaces, converts tabs and spaces, and inserts the date and time.

  5. Use several cursors

    Hold Ctrl (Cmd on Mac) and click to add a second cursor, then type to edit in both places at once. Hold Alt and drag to select a rectangle of text, which is great for editing columns. The status bar shows how many cursors you have.

  6. Find and replace

    Press Ctrl+F to open the find bar or Ctrl+H to open it with the replace row. Type the text, then press Enter or F3 for the next match and Shift+F3 for the previous one. "Count" tells you how many matches there are and "Mark all" highlights them. Tick "Match case", "Whole word" or "Regular expression" as needed, then use "Replace" or "Replace all". Search → "Find in all open tabs" lists which tabs contain the text. Press Esc to close the bar.

  7. Jump around and bookmark lines

    Ctrl+G opens "Go to line…". To bookmark a line, click its line number or press Ctrl+F2; a blue dot appears. F2 jumps to the next bookmark and Shift+F2 to the previous one. In the Search menu, "Bookmark lines that match" bookmarks every line containing your search, then "Copy bookmarked lines", "Remove bookmarked lines", "Remove lines that are not bookmarked", "Invert bookmarks" and "Clear all bookmarks" act on them.

  8. Set the language and the view

    Use the Language menu to choose a language for colours, or rename the tab with an extension such as .py. The View menu turns on Word wrap (Alt+Z), Line numbers, "Show spaces and tabs", "Highlight current line" and "Dark editor". Zoom with Alt+= and Alt+-, reset with Alt+0, fold or unfold all code blocks, and press F11 for full screen (Esc leaves it).

  9. Clean lines with the Lines menu

    These commands work on the selected lines, or on the whole document if nothing is selected. Sort A → Z, Z → A, as numbers or by length; shuffle or reverse the order; remove duplicate lines, consecutive duplicates or empty lines; number the lines; or "Split lines at a character…" such as a comma. Ctrl+Alt+Enter and Ctrl+Shift+Enter insert a blank line above or below.

  10. Use the Tools menu

    "JSON: format" makes JSON readable with indents and "JSON: minify" packs it onto one line. Base64 encode and decode, and URL encode and decode, change the selection or the whole text. "Word and character count" shows words, characters and lines below the editor, and "Keyboard shortcuts" shows a quick list of keys. Print a tab with Ctrl+P or File → "Print…".

Worked example: pulling errors out of a log file

You have server.log with 12,000 lines and want only the error lines. Press Ctrl+O and open the file; it appears in a new tab named server.log. Press Ctrl+F and type ERROR, then click "Count": it says "87 matches." Open Search → "Bookmark lines that match" and the message says "87 lines bookmarked." Then choose Search → "Remove lines that are not bookmarked", and the tab now holds only those 87 lines. Use Lines → "Remove duplicate lines" to drop repeats, then File → "Save as…" and type errors.txt to download the result.

Tips and tricks

  • Select some lines before using a Lines or Edit command to change only those lines; with nothing selected the whole document is changed, and the message under the editor says “(whole document)”. Ctrl+Z undoes it.
  • The line ending menu in the status bar (LF, CRLF or CR) sets the line breaks used when you save the tab. Files you open keep the line endings they had.
  • Rename a new tab with an extension, for example notes.md or script.py, to get the right colours and the right extension when you save.
  • Your tabs live in this browser only. To move work to another computer, use "Save all as ZIP" and open the files there.
  • Use Edit → "Copy all text" to copy the whole tab in one click without selecting.
  • If a menu shortcut does nothing, click inside the editor first so it has the keyboard focus.
  • Turn on "Show spaces and tabs" to find stray tabs or double spaces in data files and code.

Problems and how to fix them

"Print…" does not open a new window

Printing normally opens the text in a new window. If your browser blocks pop-ups, the print dialog opens from this page instead. If nothing appears at all, allow pop-ups for this site and try again.

A file opens with a message about Latin-1 or UTF-16, or is not opened

Files in older encodings (Latin-1 / Windows-1252, or UTF-16 from Windows Notepad) are read correctly and saved back as UTF-8. Images, PDFs and other files that are not text are not opened.

"That is not valid JSON"

The text has an error such as a missing comma, a trailing comma or single quotes. The message gives the position; fix it there and try "JSON: format" again.

A shortcut opens a browser feature instead

Some browsers or systems keep certain keys, such as Alt combinations. Use the same command from the menu, which always works.

My tabs disappeared

Tabs are stored per browser and per device. They are lost if you clear site data or use a private window. Save important tabs as files with Ctrl+S or "Save all as ZIP".

"This browser’s storage is full"

Very large tabs did not fit in storage. Save your work with Ctrl+S, then close tabs you no longer need.

Questions and answers

Is this the real Notepad++?

No. Notepad++ is a Windows program. This is an independent online editor with many of the same everyday features: tabs, syntax colouring, find and replace with regular expressions, line operations, code folding, multiple cursors, word wrap and zoom.

Are my files uploaded?

No. Files you open are read by your browser and stay on your device. Your tabs are saved in this browser’s storage, not on a server.

Will my tabs still be here later?

Yes, on the same browser and device. Clearing your browser data erases them, so save anything important with Ctrl+S.

Which languages are coloured?

JavaScript, TypeScript, JSON, HTML, XML, CSS, SCSS, LESS, Python, Java, C, C++, C#, Kotlin, Dart, PHP, SQL, Markdown, Shell, PowerShell, YAML, TOML, INI, Go, Rust, Ruby, Lua, Perl, R, Swift, Dockerfile, Nginx and Diff.

How do I edit several lines at once?

Hold Ctrl (Cmd on Mac) and click to add more cursors, or hold Alt and drag to select a column.

Is there a limit on lines or file size?

No fixed limit. You can write or paste as many lines as you like; only lines on screen are drawn, so long files stay smooth. Files over 50 MB ask before opening because very large files can slow a phone down.

How do bookmarks work?

Click a line number or press Ctrl+F2 to put a blue dot on that line. F2 jumps to the next bookmark. In the Search menu you can bookmark every line that matches a search, then copy or remove those lines.
