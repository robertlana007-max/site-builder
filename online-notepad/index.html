GetToolNest Notepad

GetToolNest Notepad is a full text and code editor in your browser, in the spirit of desktop editors such as Notepad++: write as many lines as you like, open many files in tabs, colour code in more than 30 languages, find and replace with regular expressions, bookmark lines, sort and clean lines, and save. Your tabs are kept in this browser, so they are still there tomorrow.

How to use GetToolNest Notepad

  1. Start typing, press Alt+N for a new tab, or open files with Ctrl+O (or drop them on the editor).
  2. Pick the language from the Language menu, or rename the tab with an extension such as .py or .html.
  3. Use Search for find and replace, and Lines or Edit for sorting, cleaning and changing case.
  4. Press Ctrl+S to save the current tab, or File → Save all as ZIP.

Questions and answers

Is this the real Notepad++?

No. Notepad++ is a Windows program. This is an independent online editor with many of the same everyday features: tabs, syntax colouring, find and replace with regular expressions, line operations, code folding, multiple cursors, word wrap and zoom.

Are my files uploaded?

No. Files you open are read by your browser and stay on your device. Your tabs are saved in this browser’s storage, not on a server.

Will my tabs still be here later?

Yes, on the same browser and device. Clearing your browser data erases them, so save anything important with Ctrl+S.

Which languages are coloured?

JavaScript, TypeScript, JSON, HTML, XML, CSS, SCSS, LESS, Python, Java, C, C++, C#, Kotlin, Dart, PHP, SQL, Markdown, Shell, PowerShell, YAML, TOML, INI, Go, Rust, Ruby, Lua, Perl, R, Swift, Dockerfile, Nginx and Diff.

How do I edit several lines at once?

Hold Ctrl (Cmd on Mac) and click to add more cursors, or hold Alt and drag to select a column.

Is there a limit on lines or file size?

No fixed limit. You can write or paste as many lines as you like; only lines on screen are drawn, so long files stay smooth. Files over 50 MB ask before opening because very large files can slow a phone down.

How do bookmarks work?

Click a line number or press Ctrl+F2 to put a blue dot on that line. F2 jumps to the next bookmark. In the Search menu you can bookmark every line that matches a search, then copy or remove those lines.
