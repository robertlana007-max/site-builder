Frequently asked questions

Do these QR codes expire?

No. The text is stored inside the code itself. There is no redirect and no account, so it keeps working forever.

What is error correction?

It is spare data that lets a code still scan when part of it is dirty or damaged. Higher levels survive more damage but make the pattern denser.

Can I use the codes commercially?

Yes. You can use them on packaging, menus, posters and business cards at no cost.
