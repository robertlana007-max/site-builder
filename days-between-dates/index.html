How to use Days Between Dates

  1. Pick the start date and the end date.
  2. Tick the box if the end date should be counted as a full day.
  3. Read the totals.

Frequently asked questions

Is the end date included?

Not by default, which matches how most deadlines are counted. Tick the box to include it.

Are public holidays removed from weekdays?

No. Weekdays are every Monday to Friday in the range. Holidays differ by country, so subtract them yourself.

Does it handle leap years?

Yes. Real calendar dates are used, so 29 February is counted when it exists.
