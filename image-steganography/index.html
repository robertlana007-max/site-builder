What is Image Steganography?

Image Steganography hides a text message inside a picture. The picture looks the same, but the message is stored in the tiniest colour changes of its pixels (the lowest bit of red, green and blue). Reveal mode reads it back.

You can also lock the message with a password (AES-256-GCM, PBKDF2-SHA256 with 600,000 rounds), so even someone who knows a message is hidden cannot read it. A small header with the length and a checksum tells you if the picture was changed.

The result is always a PNG, because JPEG compression and apps that shrink photos destroy hidden messages. Everything runs on your device.

Step-by-step tutorial: how to use Image Steganography

  1. Pick a picture

    Click the box and choose a PNG, JPG, WebP, GIF or BMP. Bigger pictures hold more text; the line under the preview shows how much room there is.

  2. Type the message

    Type the secret message. The counter shows how many bytes it uses and turns red if it does not fit.

  3. Add a password (optional)

    Tick "Also lock the message with a password" and type it twice. Without it, anyone using a tool like this can read the message.

  4. Hide and download

    Press "Hide message". The tool checks the new picture really holds the message, then you press Download PNG.

  5. Send it as a file

    Email it as an attachment, share it in a cloud drive, or use "send as document" in a chat app. Sending it as a photo would destroy the message.

  6. Reveal

    Choose "Reveal a message" and pick the PNG. The message appears, or a password box if it is locked.

Features

  • Shows the capacityWidth, height and how many bytes fit, updated as you type.
  • Length and checksum headerA CRC-32 checksum tells a damaged message apart from no message at all.
  • Optional passwordAES-256-GCM encryption with a strong password-based key.
  • Always PNGPNG is lossless, so every hidden bit stays exactly as written.
  • Self-checkThe new picture is read back before you download it, to be sure the message is there.
  • Clear JPEG warningsIf a picture was recompressed, it says so plainly instead of showing garbage.
  • Works with any languageMessages are stored as UTF-8, so Arabic, Chinese, Hindi and emoji all work.

Worked example: a clue in a holiday photo

Your photo beach.jpg is 1600 × 1200 pixels, so it has room for about 720,000 bytes. You type "The next clue is under the blue chair" and press Hide message. You download beach-hidden.png (about 3 MB, bigger than the JPG because PNG is lossless) and email it to your friend. They open Reveal a message, pick the PNG and read the clue. When they post the same picture on social media, the app recompresses it, and the message is gone, which is why you sent it as a file.

Tips and tricks

  • Always share the PNG as a file or document, never as a photo in a chat or social app.
  • Do not edit, crop, resize or re-save the picture as JPEG after hiding a message.
  • Use a password if the message is private; hiding alone is not security.
  • Photos with lots of detail hide changes best, but any picture works.
  • Fully see-through pixels are skipped, so pictures with big transparent areas hold less.

Problems and how to fix them

"No hidden message found" with a JPEG

JPEG compression destroys hidden messages. Ask for the original PNG file, sent as a document or attachment.

"A hidden message was found, but it is damaged"

The picture was changed after the message was hidden (recompressed, resized or edited). Get the original PNG.

"The message is too long for this picture"

Shorten the message or use a bigger picture.

"Wrong password or damaged data"

Check the password, including capital letters. If it is right, the picture was changed.

Questions and answers

Why is the result always a PNG?

PNG keeps every pixel exactly. JPEG and WebP compression change the tiny colour details that hold the message, so the message would be lost.

Can I send the picture on WhatsApp or post it on social media?

Not as a photo: those apps shrink and recompress pictures, which destroys the message. Send it as a file or document, by email, or through a cloud drive.

How much text fits?

About 3 bits per pixel, so a 1600 × 1200 picture holds around 720,000 bytes. The tool shows the exact room for your picture.

Is a hidden message secure?

Hiding only makes it hard to notice. Anyone who suspects a message can read it with a tool like this, unless you also lock it with a password (AES-256-GCM).

What if the picture was changed?

A checksum in the header tells you the message is damaged, instead of showing garbage. A JPEG copy usually shows "no hidden message".
