This tool works by turning each page into a compressed picture. It is best for scanned documents and PDFs full of photos. Text in the result can no longer be selected or searched.

How to use Compress PDF

  1. Choose a PDF.
  2. Pick a compression level. Start with Medium.
  3. Click Compress PDF and compare the sizes.
  4. Download the result if you are happy with it.

Questions people ask

How does this compress the PDF?

Each page is redrawn as a compressed picture and a new PDF is built from those pictures.

Will I still be able to select text?

No. Pages become images, so text can no longer be selected or searched. Keep your original if you need that.

Why did my file not get smaller?

PDFs that are mostly text are already tiny. Turning them into pictures makes them larger, so the tool tells you to keep the original.

Is my file uploaded?

No. Compression happens on your device.
