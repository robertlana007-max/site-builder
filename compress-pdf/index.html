What is Compress PDF?

Compress PDF makes a PDF file smaller so it fits email limits, upload limits on job or government websites, or simply takes less space. You choose how strong the compression should be, and the tool shows the old size, the new size and how much you saved.

It works by drawing every page as a picture and saving that picture as a compressed JPG inside a new PDF. This gives big savings on scanned documents and PDFs full of photos. For PDFs that are mostly plain text it often does not help, and the tool will tell you to keep your original.

Everything happens in your browser. Your PDF is not uploaded to any server.

What you can use it for

Meet an upload limit

Many forms only accept files under 1 MB or 2 MB. Compress a scanned ID or certificate to fit.

Email a large scan

Phone scanner apps often create very large PDFs. Compress them before attaching to an email.

Save storage space

Shrink old scanned letters and receipts that you keep only for your records.

Share photo-heavy documents

Brochures and photo reports become much easier to send after compression.

Step-by-step tutorial: how to use Compress PDF

  1. Choose your PDF

    Click "Click or drop a PDF here" or drag a PDF onto the box. The tool shows the file name and its current size, for example "scan.pdf · 8.4 MB".

  2. Pick a "Compression" level

    "Light (best quality)" draws pages at about 144 dpi with JPG quality 80%. "Medium" uses about 108 dpi and quality 65%, and is the default. "Strong (smallest file)" uses about 79 dpi and quality 50%, which gives the smallest file but softer text.

  3. Read the note under the options

    It reminds you that pages become pictures. After compression, the text can no longer be selected, copied or searched.

  4. Click "Compress PDF"

    The tool works page by page and shows "Compressing page 3 of 10…" so you can follow the progress. Long files take longer, especially on a phone.

  5. Compare the sizes

    Three boxes appear: "Original", "Compressed" and "Saved". "Saved" is the percentage the file shrank, worked out as 1 minus new size divided by old size.

  6. Download or try another level

    If you are happy, click "Download PDF". The file is named like scan-compressed.pdf. If it is still too big, choose "Strong" and click "Compress PDF" again. If the text is too blurry, try "Light".

Features

  • Three compression levelsLight, Medium and Strong let you balance quality against file size.
  • Before and after sizesSee the original size, the new size and the percentage saved before you download.
  • Honest result checkIf the compressed file would be bigger than the original, the tool does not offer it and tells you to keep the original.
  • Page-by-page progressA live message shows which page is being processed.
  • Same page sizesEach new page has exactly the same size as the original page, so printing is not affected.
  • Up to 200 pagesFiles with up to 200 pages can be compressed in one go.

Worked example: a scanned form for an online application

Lina scanned a 6-page form with her phone and got form.pdf at 9.2 MB, but the website only accepts files up to 2 MB. She loads it and keeps "Medium". After "Compress PDF" the boxes show Original 9.2 MB, Compressed 1.6 MB and Saved 83%, because 1 minus 1.6 divided by 9.2 is about 0.83. She zooms into the preview of form-compressed.pdf, finds the text easy to read, and uploads it.

Tips and tricks

  • Start with Medium. Only move to Strong if the file is still too big.
  • Keep your original file. The compressed copy has no selectable text, so you may need the original later.
  • If a PDF is mostly typed text and already small, compression will not help. That is normal.
  • For a PDF over 200 pages, use Split PDF to cut it into parts, compress each part, then join them with Merge PDF.
  • Removing pages you do not need with Delete PDF Pages is another simple way to make a file smaller.

Problems and how to fix them

The message says "This PDF is already small"

The picture version would be larger than your original. Keep the original, or try "Strong" once. Text-only PDFs usually cannot be made smaller this way.

The message says the PDF has more than 200 pages

Split the file into smaller parts with Split PDF, compress each part, and merge them again if needed.

The text looks blurry

Choose "Light (best quality)" and compress again. It keeps more detail but makes a bigger file.

A message says a page "is too large to process on this device"

The page is huge, such as a poster or plan. Try "Strong", which draws pages smaller, or use a computer with more memory.

I cannot select or search text in the new file

This is expected. Pages are turned into pictures. Use the original file when you need to copy text.

Questions and answers

How does this compress the PDF?

Each page is redrawn as a compressed picture and a new PDF is built from those pictures.

Will I still be able to select text?

No. Pages become images, so text can no longer be selected or searched. Keep your original if you need that.

Why did my file not get smaller?

PDFs that are mostly text are already tiny. Turning them into pictures makes them larger, so the tool tells you to keep the original.

Is my file uploaded?

No. Compression happens on your device.
