How to use Add Page Numbers to PDF

  1. Choose a PDF.
  2. Pick the position and number format.
  3. Set the starting number if it should not be 1.
  4. Click Add page numbers, then Download.

Questions people ask

Can I start from a number other than 1?

Yes. Change "Start at" to any number.

Can I skip the cover page?

Not directly. Split the cover off first, number the rest, then merge the two files.

Will the numbers cover my content?

They sit in the page margin, about one centimetre from the edge. Check the result if your pages have very small margins.
