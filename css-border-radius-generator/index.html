What is CSS Border Radius Generator?
The CSS Border Radius Generator rounds the corners of a box and shows the result on a live preview. You can give every corner the same value or a different one, and use elliptical corners for blobs, eggs, leaves and other organic shapes.
It writes the shortest correct border-radius CSS for you, including the slash syntax for elliptical corners, so you do not have to remember the order of the values.
It runs entirely in your browser.


What you can use it for
Rounded cards and buttons
Pick a radius that matches your design system, such as 8px or 16px.
Circles and pills
Use 50% for a circle or oval avatar, or a very large pixel value for a pill-shaped button.
Speech bubbles and tabs
Round three corners and leave one square.
Organic blob shapes
Use elliptical corners with different horizontal and vertical values for hero images and decorations.
Learning the syntax
See how the four values and the slash map to each corner.


Step-by-step tutorial: how to use CSS Border Radius Generator
  1. Pick a unit
    Choose Pixels for a fixed curve, or Percent for a curve that scales with the box. 50% on all corners makes a circle or oval.
  2. Set all corners at once
    With Same value for all corners ticked, moving any slider changes all four.
  3. Set corners one by one
    Untick Same value for all corners and use the slider or number box for Top left, Top right, Bottom right and Bottom left.
  4. Make elliptical corners
    Tick Elliptical corners to get a Horizontal and a Vertical value for each corner. Different values stretch the curve into an ellipse.
  5. Test with a different box size
    Change Box width and Box height to see how your radius looks on wide or tall elements.
  6. Copy the CSS
    Start from a preset if you like, then click Copy CSS. The code is shortened the same way CSS does, for example 24px 50px instead of four values.


Features
  • Per-corner controlEach corner has a slider and an exact number box.
  • Elliptical cornersSeparate horizontal and vertical radii, written with the slash syntax.
  • Pixels or percentSwitch units at any time; values are kept within range.
  • Shortest CSSRepeated values are collapsed to the shortest valid form.
  • Eight presetsRounded, circle, pill, leaf, speech bubble, blob, egg and drop.


Worked example: a leaf shape
Choose Percent, untick Same value for all corners, and set Top left 0, Top right 70, Bottom right 0 and Bottom left 70. The code becomes border-radius: 0 70%;, because CSS repeats the first two values for the last two corners. On a 260 × 200 box this gives a leaf. Tick Elliptical corners and set different vertical values to make it lean.


Tips and tricks
  • A radius larger than half the box size is reduced by the browser, so 999px is a safe way to make pills of any size.
  • Use percent for avatars and images that may change size, and pixels for buttons and cards so the curve stays consistent.
  • Nested rounded boxes look best when the inner radius equals the outer radius minus the padding.
  • Rounded corners also clip a background image, but child elements only if the parent has overflow: hidden.


Problems and how to fix them
The corners do not look round
The element may be too small for the radius, or a border-radius set later in your CSS overrides it.
Content sticks out of the corners
Add overflow: hidden to the rounded element so images and child elements are clipped too.
Percent values seem squashed
Percentages are relative to the width for horizontal radii and to the height for vertical radii, so on a rectangle 50% makes an oval, not a circle.



Questions and answers


What does the slash in border-radius mean?
Values before the slash are the horizontal radii and values after it are the vertical radii, in the order top left, top right, bottom right, bottom left.
How do I make a circle?
Use 50% on all corners on a square element. On a rectangle, 50% gives an oval.
Why is my 500px radius the same as 100px?
When the curves would overlap, browsers scale all radii down so they fit, so very large values all look the same.
Does border-radius work on images?
Yes. Put it on the img element, or on a parent with overflow: hidden.
