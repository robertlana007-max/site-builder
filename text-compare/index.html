What is Text Compare?

Text Compare shows the differences between two versions of a text, line by line. You paste the original on the left and the changed version on the right, click "Compare", and it lists every line, marking lines that were added with a plus sign and lines that were removed with a minus sign.

It is useful when you need to know exactly what changed: an edited contract or essay, two versions of a configuration file or code, an old and new price list, or two copies of a list where one may have missing items. It saves you reading both texts side by side and guessing.

The comparison is done in your browser, so private documents are not uploaded.

What you can use it for

Check edits to a document

See which sentences an editor, teacher or colleague added or removed in a contract, letter or essay.

Compare code or settings

Find the changed lines between two versions of a config file, script or web page source.

Find missing list items

Compare two lists, such as yesterday’s and today’s orders, to see what was added or dropped.

Verify a copy

Confirm that two texts are exactly the same, for example after copying between programs.

Review translations or templates

Compare two templates to see which lines were customised.

Step-by-step tutorial: how to use Text Compare

  1. Paste the first version

    Click the "Original text" box and paste the older or original version.

  2. Paste the second version

    Click the "Changed text" box and paste the newer version. The order matters: lines only in the right box count as added, lines only in the left box count as removed.

  3. Choose what to ignore

    Tick "Ignore spaces at the start and end of lines" if changes in indentation or trailing spaces do not matter to you. Tick "Ignore upper/lower case" if "Hello" and "hello" should count as the same line.

  4. Click "Compare"

    A summary message appears, such as "3 lines added, 2 lines removed.", or "The two texts are identical." if nothing changed.

  5. Read the result list

    Below the message every line is shown in order. Unchanged lines have no sign. Added lines start with + and are highlighted as additions. Removed lines start with − and are highlighted as removals. A line that was edited shows as one removed line followed by one added line.

  6. Change and compare again

    Edit either box or change the options, then click "Compare" again to refresh the result.

Features

  • Line-by-line comparisonFinds the smallest set of added and removed lines using a longest-common-subsequence method, the same idea used by programmers’ diff tools.
  • Clear + and − marksAdded and removed lines are signed and coloured so they stand out.
  • Summary countTells you how many lines were added and removed in one sentence.
  • Ignore spaces optionSkips differences in spaces at the start and end of lines.
  • Ignore case optionTreats capital and small letters as the same.
  • Identical checkConfirms when two texts match exactly.

Worked example: a shopping list

The original text has four lines: Milk, Eggs, Bread, Butter. The changed text has: Milk, Bread, Butter, Cheese, Apples. After clicking "Compare", the message says "2 lines added, 1 line removed." The list shows Milk unchanged, "− Eggs" as removed, Bread and Butter unchanged, then "+ Cheese" and "+ Apples" as added.

Tips and tricks

  • Put each sentence on its own line before comparing long paragraphs. A whole paragraph on one line shows as fully removed and added even if one word changed.
  • When comparing code, leave "Ignore spaces…" off if indentation matters, as in Python or YAML.
  • Blank lines are compared too. An extra empty line will show as an added line.
  • For two lists in different orders, sort both first (for example in the Notepad Lines menu), then compare.
  • Very long texts can be compared in parts, for example chapter by chapter.

Problems and how to fix them

"These texts are too long to compare here."

The number of lines on the left times the number on the right is above 4 million (for example, more than 2,000 lines in each box). Compare smaller sections.

Every line shows as changed

One text may use different line breaks or extra spaces at the line ends. Tick "Ignore spaces at the start and end of lines" and compare again.

A one-word change shows the whole line as removed and added

The tool compares whole lines, not single words. Look at the − and + pair together to spot the changed word.

Added and removed seem reversed

Check that the older text is in "Original text" and the newer text is in "Changed text".

Questions and answers

How are the texts compared?

Line by line. A line that changed is shown as the old line removed and the new line added.

Is my text uploaded?

No. The comparison happens in your browser.

Can it ignore small differences?

Yes. Tick the options to ignore leading and trailing spaces or upper and lower case.
